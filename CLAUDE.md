# CLAUDE.md

Указания для Claude Code при работе в этом репозитории.

## Pull Requests и авто-мерж

Закончив задачу на фиче-ветке (изменения закоммичены и запушены, сборка
`npm run build:site` проходит):

1. Создавай pull request в `main`.
2. Включай на нём auto-merge.
3. Если в репозитории нет обязательных проверок / branch protection и мерж не
   происходит автоматически — мержи PR сразу после создания (squash-мерж).

Исключение: не создавай PR и не мержи, если пользователь явно попросил этого не
делать в конкретной задаче.

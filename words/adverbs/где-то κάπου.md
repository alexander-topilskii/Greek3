# База
где-то : κάπου

# Тип
αόριστη

# Формы
κάπου - где-то / куда-то
# Контекст
- **Ψάχνω κάπου να κάτσω.** — Ищу где-то присесть.
- **Κάπου άκουσα αυτό το τραγούδι.** — Где-то я слышал эту песню.
- **Πήγα κάπου για διακοπές.** — Я поехал куда-то в отпуск.
- **Κάπου εδώ πρέπει να είναι.** — Где-то здесь это должно быть.

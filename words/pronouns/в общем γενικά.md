# База
в общем / обычно : γενικά

# Тип
χρόνος

# Формы
γενικά - в общем; обычно; как правило

# Контекст
- **Γενικά, πώς είσαι όταν είσαι άρρωστος;** — Вообще, как ты себя чувствуешь, когда болеешь?
- **Ο γιατρός συμβουλεύει γενικά να ξεκουράζεσαι.** — Врач в целом советует отдыхать.

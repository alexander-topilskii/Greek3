# База
аналитически / подробно : αναλυτικά

# Тип
επίρρημα

# Формы
αναλυτικά - аналитически; подробно

# Контекст
- **Χρησιμοποιείς αναλυτικά τα δεδομένα.** — Ты аналитически используешь данные.
- **Εξήγησε αναλυτικά την εμπειρία σου.** — Подробно объясни свой опыт.

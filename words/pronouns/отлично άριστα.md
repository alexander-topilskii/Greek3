# База
отлично (оценка) : άριστα

# Тип
επίρρημα

# Формы
άριστα - отлично (оценка)
άριστος - отличный (м.р.)

# Контекст
- **Πήρα άριστα στο μάθημα.** — Я получил отличную оценку по предмету.
- **Τα πήγε άριστα στις εξετάσεις.** — На экзаменах у него всё прошло отлично.

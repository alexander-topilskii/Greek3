# База
конкретно / в частности : συγκεκριμένα

# Тип
επίρρημα

# Формы
συγκεκριμένα - конкретно; в частности
συγκεκριμένος - конкретный (м.р.)
συγκεκριμένη - конкретная (ж.р.)
συγκεκριμένο - конкретное (с.р.)

# Контекст
- **Συγκεκριμένα, η ανεργία έφτασε το 12%.** — В частности, безработица достигла 12%.
- **Θέλω συγκεκριμένα στοιχεία για το δεύτερο τρίμηνο.** — Мне нужны конкретные данные по второму кварталу.

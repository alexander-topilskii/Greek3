# Όλα τα Ρήματα

Настоящее, будущее и формы с «να».

## Текст

- Εγώ πληρώνω και αγοράζω. — Я плачу и покупаю.
- Θα πληρώσω, πρέπει να αγοράσω. — Я заплачу, нужно купить.
- Αλλάζω, ανοίγω, προσέχω, φτιάχνω. — Меняю, открываю, слежу, чиню.
- Θα αλλάξω, θα ανοίξω, θα προσέξω, θα φτιάξω. — Поменяю, открою, послежу, починю.
- Δουλεύω πολύ, από το σπίτι λείπω. — Много работаю, меня нет дома.
- Γράφω ένα γράμμα και το χρόνο κλέβω. — Пишу письмо и краду время.
- Θα δουλέψω, θα λείψω, θα γράψω, θα κλέψω. — Поработаю, меня не будет, напишу, украду.
- Θέλω να δουλέψω, πρέπει να κλέψω. — Хочу поработать, нужно украсть.
- Εγώ είμαι εδώ και το χρόνο τον έχω. — Я здесь, и время у меня есть.
- Θα είμαι καλά και θα έχω τι θέλω. — Буду в порядке и буду иметь то, что хочу.
- Κάνω, ξέρω, σε περιμένω. — Делаю, знаю, жду тебя.
- Θα κάνω, θα ξέρω, θα περιμένω. — Сделаю, буду знать, подожду.
- Μπορώ να είμαι, πρέπει να έχω, θέλω να κάνω. — Могу быть, нужно иметь, хочу сделать.
- Να ξέρω, να περιμένω. — Знать, ждать.
- Πρέπει να βάλω, να βγάλω, να δώσω, να καταλάβω, να μάθω, να μείνω. — Нужно положить, вынуть, дать, понять, выучить, остаться.
- Να πάρω, να πέσω, να πλύνω, να στείλω, να φέρω, να φύγω. — Взять, упасть, помыть, послать, принести, уйти.
- Βάζω και βγάζω. Σου δίνω το λόγο. — Кладу и вынимаю. Даю тебе слово.
- Θα βάλω, θα βγάλω, θα δώσω το χρόνο. — Положу, выну, отдам время.
- Καταλαβαίνω, μαθαίνω και μένω. — Понимаю, учусь и остаюсь.
- Θα καταλάβω, θα μάθω, θα μείνω. — Пойму, выучу, останусь.
- Παίρνω τα πράγματα, πέφτω στο χώμα. — Беру вещи, падаю на землю.
- Πλένω τα ρούχα, το κάνω ακόμα. — Стираю одежду и всё ещё это делаю.
- Στέλνω, φέρνω και μετά φεύγω. — Посылаю, приношу и потом ухожу.
- Θα στείλω, θα φέρω, θα φύγω, το ξέρω. — Пошлю, принесу, уйду — я это знаю.
- Γίνομαι φίλος και έρχομαι τώρα. — Становлюсь другом и прихожу сейчас.
- Κάθομαι κάτω. Περνάει η ώρα. — Сажусь. Время идёт.
- Θα γίνω, θα καθίσω κάτω. — Стану, сяду.
- Θέλω να γίνω, να έρθω, να καθίσω, να κάτσω. — Хочу стать, прийти и сесть.
- Πρέπει να βάλω, να βγάλω, να δώσω, να καταλάβω, να μάθω, να μείνω. — Нужно положить, вынуть, дать, понять, выучить, остаться.
- Να πάρω, να πέσω, να πλύνω, να στείλω, να φέρω, να φύγω. — Взять, упасть, помыть, послать, принести, уйти.
- Βλέπω, βρίσκω, λέω και πίνω. — Вижу, нахожу, говорю и пью.
- Αυτό είναι το τραγούδι που κρίνω. — Это песня, которую я оцениваю.
- Θα δω, θα βρω, θα πω, θα πιω. — Увижу, найду, скажу, выпью.
- Πρέπει να δω, να βρω, να πω, να πιω. — Нужно увидеть, найти, сказать, выпить.
- Βγαίνω και μπαίνω, ανεβαίνω, κατεβαίνω. — Выхожу и вхожу, поднимаюсь, спускаюсь.
- Θα βγω και θα μπω, θα ανεβώ, θα κατεβώ. — Выйду и войду, поднимусь, спущусь.
- Πρέπει να βγω, να μπω, να ανεβώ, να κατεβώ. — Нужно выйти, войти, подняться, спуститься.
- Όλα τα ρήματα και τα κρατάω. — Все глаголы, и я их держу.
- Πρέπει να βάλω, να βγάλω, να δώσω, να καταλάβω, να μάθω, να μείνω. — Нужно положить, вынуть, дать, понять, выучить, остаться.
- Να πάρω, να πέσω, να πλύνω, να στείλω, να φέρω, να φύγω. — Взять, упасть, помыть, послать, принести, уйти.

# База
чтобы посмотреть / дайте взглянуть : Για να δω

# Формы
Για - для; чтобы
να - (связка)
δω - посмотрю; увижу
Για να δω - чтобы посмотреть; дайте взглянуть

# Контекст
- **Για να δω…** — Дайте взглянуть…
- **Έλα εδώ, για να δω.** — Иди сюда, дай посмотрю.

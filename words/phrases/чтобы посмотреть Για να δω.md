# База
чтобы посмотреть : Για να δω

# Формы
Για - для; чтобы
να - частица сослагательного
δω - я увижу; посмотрю
Για να δω - чтобы я посмотрел; дайте посмотреть

# Контекст
- **Για να δω τι έχετε.** — Чтобы посмотреть, что у вас есть.
- **Μια στιγμή, για να δω.** — Минутку, дайте посмотреть.

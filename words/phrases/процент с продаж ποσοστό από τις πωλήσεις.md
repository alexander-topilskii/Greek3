# База
процент с продаж : ποσοστό από τις πωλήσεις

# Формы
ποσοστό - процент
από - с
τις πωλήσεις - продаж
ποσοστό από τις πωλήσεις - процент с продаж

# Контекст
- **Ο μισθός έχει ποσοστό από τις πωλήσεις.** — В зарплате есть процент с продаж.

# База
последние два года : τα τελευταία δύο χρόνια

# Формы
τα τελευταία - последние (с.р. мн.)
δύο - два
χρόνια - годы
τα τελευταία δύο χρόνια - последние два года

# Контекст
- **Τα τελευταία δύο χρόνια η ανεργία έπεσε.** — За последние два года безработица снизилась.
- **Τα τελευταία δύο χρόνια έχασε τη δουλειά του.** — За последние два года он потерял работу.

# База
если хочешь уйти — уходи : Αν θέλεις να φύγεις, φύγε

# Формы
αν - если
θέλεις - хочешь
να φύγεις - уйти
φύγε - уходи
Αν θέλεις να φύγεις, φύγε - если хочешь уйти — уходи

# Контекст
- **Αν θέλεις να φύγεις, φύγε. Αν δε θέλεις, μη φύγεις.** — Если хочешь уйти — уходи. Если нет — не уходи.

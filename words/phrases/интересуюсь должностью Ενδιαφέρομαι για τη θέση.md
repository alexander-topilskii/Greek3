# База
интересуюсь должностью : Ενδιαφέρομαι για τη θέση

# Формы
ενδιαφέρομαι - интересуюсь
για - (предлог «для / о»)
τη θέση - должностью
Ενδιαφέρομαι για τη θέση - интересуюсь должностью

# Контекст
- **Ενδιαφέρομαι για τη θέση υπαλλήλου ρεσεψιόν.** — Интересуюсь должностью сотрудника на ресепшене.

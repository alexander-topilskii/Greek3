# База
ответственная должность : υπεύθυνη θέση

# Формы
υπεύθυνη - ответственная
θέση - должность
υπεύθυνη θέση - ответственная должность

# Контекст
- **Είναι μια υπεύθυνη θέση στην εταιρεία.** — Это ответственная должность в компании.

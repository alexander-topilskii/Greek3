# База
сколько с вас? : Τι σας οφείλω;

# Формы
Τι - что; сколько
σας - вам; вас
οφείλω - я должен
Τι σας οφείλω; - сколько с вас?; что я вам должен?

# Контекст
- **Τι σας οφείλω;** — Сколько с вас?
- **Τι σας οφείλω για τα φάρμακα;** — Сколько с вас за лекарства?

# База
я уже два года не ездил : Έχω δύο χρόνια να πάω

# Формы
έχω - у меня есть; (здесь) прошло [времени]
δύο - два
χρόνια - года; годы
να πάω - пойти; поехать
Έχω δύο χρόνια να πάω - я уже два года не ездил

# Контекст
- **Έχω δύο χρόνια να πάω στο χωριό.** — Я уже два года не ездил в деревню.
- **Έχω καιρό να τον δω.** — Я давно его не видел.

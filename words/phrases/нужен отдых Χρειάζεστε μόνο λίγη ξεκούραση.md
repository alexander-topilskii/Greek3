# База
вам нужен только небольшой отдых : Χρειάζεστε μόνο λίγη ξεκούραση

# Формы
χρειάζεστε - вам нужно
μόνο - только
λίγη ξεκούραση - немного отдыха
Χρειάζεστε μόνο λίγη ξεκούραση - вам нужен только небольшой отдых

# Контекст
- **Χρειάζεστε μόνο λίγη ξεκούραση.** — Вам нужен только небольшой отдых.

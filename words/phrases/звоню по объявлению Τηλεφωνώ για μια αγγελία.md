# База
звоню по объявлению : Τηλεφωνώ για μια αγγελία

# Формы
τηλεφωνώ - звоню
για - по; насчёт
μια - одно
αγγελία - объявление
Τηλεφωνώ για μια αγγελία - звоню по объявлению
Τηλεφωνώ για την αγγελία σας - звоню по вашему объявлению

# Контекст
- **Καλημέρα. Τηλεφωνώ για την αγγελία σας.** — Доброе утро. Звоню по вашему объявлению.
- **Τηλεφωνώ για μια αγγελία στο Ίντερνετ.** — Звоню по объявлению в интернете.

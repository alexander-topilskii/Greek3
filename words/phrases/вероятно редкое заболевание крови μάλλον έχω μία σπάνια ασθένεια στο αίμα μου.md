# База
вероятно, у меня редкое заболевание крови : Μάλλον έχω μία σπάνια ασθένεια στο αίμα μου

# Формы
μάλλον - вероятно
έχω - у меня есть
μία σπάνια ασθένεια - редкая болезнь
στο αίμα μου - в моей крови
Μάλλον έχω μία σπάνια ασθένεια στο αίμα μου - вероятно, у меня редкое заболевание крови

# Контекст
- **Μάλλον έχω μία σπάνια ασθένεια στο αίμα μου.** — Вероятно, у меня редкое заболевание крови.

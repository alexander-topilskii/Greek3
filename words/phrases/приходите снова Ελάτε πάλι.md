# База
приходите снова : Ελάτε πάλι

# Формы
Ελάτε - приходите
πάλι - снова; ещё раз
Ελάτε πάλι - приходите снова

# Контекст
- **Ελάτε πάλι αν δεν περάσει.** — Приходите снова, если не пройдёт.
- **Ελάτε πάλι σε μία εβδομάδα.** — Приходите снова через неделю.

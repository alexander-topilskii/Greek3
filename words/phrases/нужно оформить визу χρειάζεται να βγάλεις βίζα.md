# База
нужно оформить визу : χρειάζεται να βγάλεις βίζα

# Формы
χρειάζεται - нужно; необходимо
να βγάλεις - чтобы ты оформил; достал
βίζα - виза
χρειάζεται να βγάλεις βίζα - нужно оформить визу

# Контекст
- **Για την Κίνα χρειάζεται να βγάλεις βίζα.** — Для Китая нужно оформить визу.

# База
проживание в одноместном : διαμονή σε μονόκλινο

# Формы
διαμονή - проживание
σε - в
μονόκλινο - одноместный (номер)
διαμονή σε μονόκλινο - проживание в одноместном номере

# Контекст
- **Η προσφορά περιλαμβάνει διαμονή σε μονόκλινο.** — Предложение включает проживание в одноместном номере.

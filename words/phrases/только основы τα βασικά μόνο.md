# База
только основы : τα βασικά μόνο

# Формы
τα βασικά - основы; основное
μόνο - только
τα βασικά μόνο - только основы

# Контекст
- **Θέλω να μάθω τα βασικά μόνο.** — Я хочу выучить только основы.
- **Στην αρχή, τα βασικά μόνο.** — Сначала только основы.

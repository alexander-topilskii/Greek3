# База
не читай : μη διαβάσεις

# Формы
μη - не
διαβάσεις - читай (форма να)
μη διαβάσεις - не читай
μη(ν) + προστακτική - не … (отрицательная команда)

# Контекст
- **Μη διαβάσεις αυτό το γράμμα.** — Не читай это письмо.
- **Να μη διαβάσεις = μη διαβάσεις.** — Чтобы ты не читал = не читай.

# База
нужно носить очки : πρέπει να φορέσει γυαλιά

# Формы
πρέπει - нужно
να φορέσει - чтобы он/она носил(а)
γυαλιά - очки
πρέπει να φορέσει γυαλιά - нужно носить очки

# Контекст
- **Δε βλέπει μακριά, πρέπει να φορέσει γυαλιά.** — Плохо видит вдаль, нужно носить очки.

# База
приходите ещё : Ελάτε πάλι

# Формы
Ελάτε - приходите
πάλι - снова; ещё раз
Ελάτε πάλι - приходите ещё; заходите снова

# Контекст
- **Ελάτε πάλι αν χρειαστείτε.** — Приходите ещё, если понадобится.
- **Ελάτε πάλι σε δύο μέρες.** — Приходите снова через два дня.

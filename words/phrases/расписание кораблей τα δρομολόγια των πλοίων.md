# База
расписание кораблей / паромов : τα δρομολόγια των πλοίων

# Формы
τα δρομολόγια - расписание; маршруты
των πλοίων - кораблей; паромов (род. мн.)
τα δρομολόγια των πλοίων - расписание паромов

# Контекст
- **Κοίταξα τα δρομολόγια των πλοίων για τα νησιά.** — Я посмотрел расписание паромов на острова.

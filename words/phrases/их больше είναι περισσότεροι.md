# База
больше (их больше) : είναι περισσότεροι

# Формы
είναι - являются; есть
περισσότεροι - большие; более многочисленные (мн. м.р.)
είναι περισσότεροι - их больше

# Контекст
- **Οι άνεργοι είναι περισσότεροι φέτος.** — Безработных в этом году больше.
- **Οι άνδρες είναι περισσότεροι έναντι των γυναικών.** — Мужчин больше по сравнению с женщинами.

# База
хочу отправить письмо : Θέλω να στείλω ένα γράμμα — απλό / εξπρές / συστημένο

# Формы
θέλω - хочу
να στείλω - отправить
ένα γράμμα - письмо
απλό / εξπρές / συστημένο - простое / экспресс / заказное
Θέλω να στείλω ένα γράμμα - хочу отправить письмо

# Контекст
- **Θέλω να στείλω ένα γράμμα — απλό / εξπρές / συστημένο.** — Хочу отправить письмо — простое / экспресс / заказное.

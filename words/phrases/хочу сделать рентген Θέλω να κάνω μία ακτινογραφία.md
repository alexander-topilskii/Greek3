# База
хочу сделать рентген : Θέλω να κάνω μία ακτινογραφία

# Формы
Θέλω - хочу
να - чтобы; частица
κάνω - делаю
μία - одну (ж.р.)
ακτινογραφία - рентген
Θέλω να κάνω μία ακτινογραφία - хочу сделать рентген

# Контекст
- **Θέλω να κάνω μία ακτινογραφία.** — Хочу сделать рентген.
- **Ο γιατρός είπε να κάνω μία ακτινογραφία.** — Врач сказал сделать рентген.

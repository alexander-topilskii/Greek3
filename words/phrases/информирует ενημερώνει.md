# База
информирует / сообщает : ενημερώνει

# Формы
ενημερώνει - информирует, сообщает, уведомляет
ενημερώνω - информирую, сообщаю

# Контекст
- **Ο υπάλληλος ενημερώνει τον πολίτη για τα δικαιολογητικά.** — Сотрудник информирует гражданина о подтверждающих документах.
- **Μας ενημερώνει για κάθε αλλαγή.** — Он информирует нас о каждом изменении.

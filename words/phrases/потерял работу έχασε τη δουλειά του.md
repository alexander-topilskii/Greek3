# База
потерял работу : έχασε τη δουλειά του

# Формы
έχασε - он/она потерял(а)
τη δουλειά - работу (вин.)
του - его
έχασε τη δουλειά του - он потерял работу

# Контекст
- **Έχασε τη δουλειά του πέρυσι.** — Он потерял работу в прошлом году.
- **Πολλοί άνθρωποι έχασαν τη δουλειά τους.** — Многие люди потеряли работу.

# База
заявка на кредитную карту : αίτηση για πιστωτική κάρτα

# Формы
αίτηση - заявка
για - на
πιστωτική κάρτα - кредитную карту
αίτηση για πιστωτική κάρτα - заявка на кредитную карту

# Контекст
- **Κάνω αίτηση για πιστωτική κάρτα.** — Подаю заявку на кредитную карту.

# База
знания компьютера : γνώσεις ηλεκτρονικού υπολογιστή

# Формы
γνώσεις - знания
ηλεκτρονικού υπολογιστή - компьютера (род. п.)
γνώσεις ηλεκτρονικού υπολογιστή - знания компьютера

# Контекст
- **Έχω γνώσεις ηλεκτρονικού υπολογιστή.** — У меня есть навыки работы с компьютером.

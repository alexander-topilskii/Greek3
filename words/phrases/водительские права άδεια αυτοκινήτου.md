# База
водительские права : άδεια αυτοκινήτου

# Формы
άδεια - разрешение; права
αυτοκινήτου - автомобиля (род. п.)
άδεια αυτοκινήτου - водительские права

# Контекст
- **Απαραίτητη άδεια αυτοκινήτου.** — Обязательны водительские права.

# База
воинская обязанность : στρατιωτικές υποχρεώσεις

# Формы
στρατιωτικές - воинские
υποχρεώσεις - обязанности
στρατιωτικές υποχρεώσεις - воинская обязанность

# Контекст
- **Οι στρατιωτικές υποχρεώσεις είναι εκπληρωμένες.** — Воинская обязанность исполнена.

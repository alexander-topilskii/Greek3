# База
сделайте глубокий вдох : Πάρτε μια βαθιά αναπνοή

# Формы
πάρτε - возьмите; сделайте
βαθιά - глубокий
αναπνοή - вдох
Πάρτε μια βαθιά αναπνοή - сделайте глубокий вдох

# Контекст
- **Πάρτε μια βαθιά αναπνοή.** — Сделайте глубокий вдох.

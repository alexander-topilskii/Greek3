# База
стараюсь её/его обслужить : προσπαθώ να την / τον εξυπηρετήσω

# Формы
προσπαθώ - я стараюсь
να - (частица сосл.)
την - её (вин. ж.р.)
τον - его (вин. м.р.)
εξυπηρετήσω - я обслужу
προσπαθώ να την εξυπηρετήσω - стараюсь её обслужить
προσπαθώ να τον εξυπηρετήσω - стараюсь его обслужить

# Контекст
- **Προσπαθώ να την εξυπηρετήσω ευγενικά.** — Стараюсь обслужить её вежливо.
- **Προσπαθώ να τον εξυπηρετήσω όσο καλύτερα μπορώ.** — Стараюсь обслужить его как можно лучше.

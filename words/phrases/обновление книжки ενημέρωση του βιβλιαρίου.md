# База
обновление сберегательной книжки : ενημέρωση του βιβλιαρίου

# Формы
ενημέρωση - обновление
του βιβλιαρίου - книжки
ενημέρωση του βιβλιαρίου - обновление сберегательной книжки

# Контекст
- **Θέλω ενημέρωση του βιβλιαρίου.** — Нужно обновить сберегательную книжку.

# База
прочитай её : Διάβασέ την

# Формы
διάβασε - прочитай
την - её
τες / τις - их (ж.р.)
Διάβασέ την - прочитай её
Διάβασέ τες - прочитай их

# Контекст
- **Διάβασέ την την αγγελία.** — Прочитай объявление.
- **Διάβασέ τες τις αγγελίες.** — Прочитай объявления.

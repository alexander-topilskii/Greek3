# База
запрашиваю информацию : ζητώ πληροφορίες

# Формы
ζητώ - запрашиваю
πληροφορίες - информацию
ζητώ πληροφορίες - запрашиваю информацию

# Контекст
- **Ζητώ πληροφορίες για την άδεια διαμονής.** — Запрашиваю информацию о виде на жительство.

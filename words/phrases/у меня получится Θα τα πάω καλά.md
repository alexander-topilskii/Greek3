# База
у меня получится? : Θα τα πάω καλά;

# Формы
θα πάω - пойду; справлюсь
τα - это (ср.р. мн., идиома)
καλά - хорошо
Θα τα πάω καλά; - у меня получится?

# Контекст
- **Θα τα πάω καλά στη συνέντευξη;** — У меня получится на собеседовании?

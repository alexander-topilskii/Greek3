# База
уведомляет по телефону : ειδοποιεί τηλεφωνικά

# Формы
ειδοποιεί - уведомляет
τηλεφωνικά - по телефону
ειδοποιεί τηλεφωνικά - уведомляет по телефону

# Контекст
- **Το ΚΕΠ ειδοποιεί τηλεφωνικά τον πολίτη.** — КЕП уведомляет гражданина по телефону.

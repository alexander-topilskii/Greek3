# База
пойдём на работу / за работой : Πάμε για δουλειά

# Формы
πάμε - пойдём
για - за; на
δουλειά - работу
Πάμε για δουλειά - пойдём на работу / за работой

# Контекст
- **Πάμε για δουλειά;** — Пойдём искать работу?
- **Πάμε για δουλειά στις οκτώ.** — Идём на работу в восемь.

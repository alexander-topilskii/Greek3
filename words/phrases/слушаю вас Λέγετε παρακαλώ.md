# База
слушаю вас : Λέγετε, παρακαλώ

# Формы
λέγετε - говорите; слушаю (по телефону)
παρακαλώ - пожалуйста
Λέγετε, παρακαλώ - слушаю вас

# Контекст
- **— Λέγετε, παρακαλώ. — Καλημέρα. Τηλεφωνώ για την αγγελία.** — — Слушаю вас. — Доброе утро. Звоню по объявлению.

# База
зачем? / по какой причине? : Για ποιο λόγο;

# Формы
για - для; за
ποιο - какой
λόγο - причину
Για ποιο λόγο; - Зачем? / По какой причине?

# Контекст
- **Για ποιο λόγο χρειάζεστε αυτό το έγγραφο;** — По какой причине вам нужен этот документ?

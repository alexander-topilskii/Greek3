# База
смогу (что-то сделать) : θα μπορέσω να

# Формы
θα - (будущее время)
μπορέσω - я смогу
να - (связка перед глаголом)
θα μπορέσω να - я смогу (что-то сделать)

# Контекст
- **Θα μπορέσω να έρθω αύριο.** — Я смогу прийти завтра.
- **Θα μπορέσω να κανονίσω τα έγγραφα.** — Я смогу уладить документы.

# База
по правде говоря, я не особо это показал(а) : Για να πω την αλήθεια, δεν το έδειξα πολύ

# Формы
για να πω την αλήθεια - по правде говоря
δεν το έδειξα - я это не показал
πολύ - особо / много
Για να πω την αλήθεια, δεν το έδειξα πολύ - по правде говоря, я не особо это показал

# Контекст
- **Για να πω την αλήθεια, δεν το έδειξα πολύ.** — По правде говоря, я не особо это показал.
- **Ήμουν χαρούμενος, αλλά για να πω την αλήθεια, δεν το έδειξα πολύ.** — Я был счастлив, но, по правде говоря, не особо это показал.

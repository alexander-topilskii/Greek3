# База
течёт из носа : Τρέχει η μύτη μου

# Формы
Τρέχει - течёт; бежит
η - (артикль)
μύτη - нос
μου - мой; мне
Τρέχει η μύτη μου - у меня течёт из носа

# Контекст
- **Τρέχει η μύτη μου.** — У меня течёт из носа.
- **Έχω συνάχι και τρέχει η μύτη μου.** — У меня насморк, и из носа течёт.

# База
не беспокойтесь : Μην ανησυχείτε

# Формы
Μην - не (запретительная частица)
ανησυχείτε - вы беспокоитесь
Μην ανησυχείτε - не беспокойтесь

# Контекст
- **Μην ανησυχείτε για τον βήχα.** — Не беспокойтесь из-за кашля.
- **Μην ανησυχείτε, όλα θα πάνε καλά.** — Не беспокойтесь, всё будет хорошо.

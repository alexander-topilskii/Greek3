# База
неохотно / нелегко идёт : δεν πηγαίνει εύκολα

# Формы
δεν - не
πηγαίνει - идёт
εύκολα - легко; легко
δεν πηγαίνει εύκολα - неохотно; нелегко идёт

# Контекст
- **Δεν πηγαίνει εύκολα η ανάρρωση.** — Выздоровление не идёт легко.
- **Δεν πηγαίνει εύκολα με το φάρμακο.** — С лекарством нелегко.

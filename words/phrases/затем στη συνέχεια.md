# База
затем / дальше : στη συνέχεια

# Формы
στη - в
συνέχεια - продолжение
στη συνέχεια - затем, далее, впоследствии

# Контекст
- **Στη συνέχεια, ο υπάλληλος ελέγχει τα έγγραφα.** — Затем сотрудник проверяет документы.
- **Στη συνέχεια θα σας ειδοποιήσουν τηλεφωνικά.** — Затем вас уведомят по телефону.

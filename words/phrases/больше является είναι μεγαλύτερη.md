# База
больше (ж.р.) : είναι μεγαλύτερη

# Формы
είναι - является; есть
μεγαλύτερη - большая; больше (ж.р.)
είναι μεγαλύτερη - (она) больше

# Контекст
- **Η ανεργία είναι μεγαλύτερη στις γυναίκες.** — Безработица выше среди женщин.
- **Η αύξηση είναι μεγαλύτερη από πέρυσι.** — Рост больше, чем в прошлом году.

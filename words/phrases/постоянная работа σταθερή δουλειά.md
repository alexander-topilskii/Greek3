# База
постоянная работа : σταθερή δουλειά

# Формы
σταθερή - постоянная
δουλειά - работа
σταθερή δουλειά - постоянная работа
μόνιμη θέση - постоянная должность

# Контекст
- **Ψάχνω σταθερή δουλειά, όχι προσωρινή.** — Ищу постоянную работу, не временную.

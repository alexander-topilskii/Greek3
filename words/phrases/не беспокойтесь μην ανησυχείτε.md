# База
не беспокойтесь : μην ανησυχείτε

# Формы
μην - не (повелит.)
ανησυχείτε - беспокойтесь
μην ανησυχείτε - не беспокойтесь

# Контекст
- **Μην ανησυχείτε, όλα είναι εντάξει.** — Не беспокойтесь, всё в порядке.
- **Μην ανησυχείτε, δεν είναι σοβαρό.** — Не беспокойтесь, это не серьёзно.

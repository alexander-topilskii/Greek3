# База
сообщает свои жалобы : αναφέρει τα παράπονά

# Формы
αναφέρει - сообщает, излагает
τα παράπονα - жалобы
αναφέρει τα παράπονά - сообщает свои жалобы

# Контекст
- **Ο πολίτης αναφέρει τα παράπονά του στο ΚΕΠ.** — Гражданин сообщает о своих жалобах в КЕП.
- **Εκεί μπορεί να αναφέρει τα παράπονά της.** — Там она может изложить свои жалобы.

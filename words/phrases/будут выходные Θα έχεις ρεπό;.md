# База
у тебя будут выходные? : Θα έχεις ρεπό;

# Формы
θα - (будущее)
έχεις - у тебя есть
ρεπό - выходной
Θα έχεις ρεπό; - у тебя будут выходные?

# Контекст
- **Θα έχεις ρεπό το Σαββατοκύριακο;** — У тебя будут выходные на выходных?
- **Ρώτησε αν θα έχεις ρεπό.** — Спроси, будут ли у тебя выходные.

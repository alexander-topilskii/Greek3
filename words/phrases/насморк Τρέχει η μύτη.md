# База
течёт из носа / насморк : Τρέχει η μύτη

# Формы
Τρέχει - течёт; бежит
η - (артикль)
μύτη - нос
Τρέχει η μύτη - течёт из носа; насморк

# Контекст
- **Τρέχει η μύτη μου.** — У меня течёт из носа.
- **Έχω κρυωμένη και τρέχει η μύτη.** — Я простужена и у меня насморк.

# База
если пойдёт дождь, соберёшь бельё : Αν βρέξει, θα μαζέψεις τα ρούχα

# Формы
αν βρέξει - если пойдёт дождь
θα μαζέψεις - соберёшь
τα ρούχα - бельё
Αν βρέξει, θα μαζέψεις τα ρούχα - если пойдёт дождь, соберёшь бельё

# Контекст
- **Αν βρέξει, θα μαζέψεις τα ρούχα.** — Если пойдёт дождь, соберёшь бельё.
- **Αν βρέξει, μάζεψε τα ρούχα.** — Если пойдёт дождь, собери бельё.

# База
образовательная программа : εκπαιδευτικό πρόγραμμα

# Формы
εκπαιδευτικό - образовательное
πρόγραμμα - программа
εκπαιδευτικό πρόγραμμα - образовательная программа

# Контекст
- **Έχει εκπαιδευτικό πρόγραμμα για παιδιά.** — Есть образовательная программа для детей.

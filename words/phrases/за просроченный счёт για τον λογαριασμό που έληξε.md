# База
за просроченный счёт : για τον λογαριασμό που έληξε

# Формы
για - за
τον λογαριασμό - счёт
που - который
έληξε - истёк
για τον λογαριασμό που έληξε - за просроченный счёт

# Контекст
- **Πληρώνω για τον λογαριασμό που έληξε.** — Плачу за просроченный счёт.

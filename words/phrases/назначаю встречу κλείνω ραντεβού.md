# База
назначаю встречу : κλείνω ραντεβού

# Формы
κλείνω ραντεβού - назначаю встречу
έχουμε ραντεβού για το διαμέρισμα - у нас встреча по квартире

# Контекст
- **Κλείνω ραντεβού στον γιατρό.** — Записываюсь к врачу.
- **Έχουμε ραντεβού για το διαμέρισμα.** — У нас встреча по квартире.

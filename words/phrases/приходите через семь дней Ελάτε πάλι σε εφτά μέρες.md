# База
приходите снова через семь дней : Ελάτε πάλι σε εφτά μέρες

# Формы
ελάτε - приходите
πάλι - снова
σε εφτά μέρες - через семь дней
Ελάτε πάλι σε εφτά μέρες - приходите снова через семь дней

# Контекст
- **Ελάτε πάλι σε εφτά μέρες.** — Приходите снова через семь дней.

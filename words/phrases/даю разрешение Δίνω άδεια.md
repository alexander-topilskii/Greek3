# База
даю разрешение : Δίνω άδεια

# Формы
δίνω - я даю
άδεια - разрешение; отпуск
Δίνω άδεια - даю разрешение

# Контекст
- **Ο διευθυντής δίνει άδεια στους υπαλλήλους.** — Директор даёт разрешение сотрудникам.
- **Δεν μπορώ να φύγω χωρίς να μου δώσει άδεια.** — Не могу уйти, пока мне не дадут разрешение.

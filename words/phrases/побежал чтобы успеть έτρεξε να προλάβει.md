# База
побежал(а), чтобы успеть : έτρεξε να προλάβει

# Формы
έτρεξε - побежал; побежала (3 л., ед.ч.)
να - чтобы
προλάβει - успеть (3 л., ед.ч.)
έτρεξε να προλάβει - побежал(а), чтобы успеть

# Контекст
- **Έτρεξε να προλάβει το ασθενοφόρο.** — Побежал(а), чтобы успеть на скорую.

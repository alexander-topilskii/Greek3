# База
на должность сотрудника ресепшена : για τη θέση υπαλλήλου ρεσεψιόν

# Формы
για - на; для
τη - (артикль ж.р. вин.)
θέση - должность
υπαλλήλου - сотрудника (род.)
ρεσεψιόν - ресепшен
για τη θέση υπαλλήλου ρεσεψιόν - на должность сотрудника ресепшена

# Контекст
- **Ενδιαφέρομαι για τη θέση υπαλλήλου ρεσεψιόν.** — Меня интересует вакансия сотрудника на ресепшене.

# База
не забудь взять что-нибудь в дорогу : Μην ξεχάσεις να πάρεις κάτι για τον δρόμο

# Формы
μην ξεχάσεις - не забудь
να πάρεις - взять
κάτι - что-нибудь
για τον δρόμο - в дорогу
Μην ξεχάσεις να πάρεις κάτι για τον δρόμο - не забудь взять что-нибудь в дорогу

# Контекст
- **Μην ξεχάσεις να πάρεις κάτι για τον δρόμο.** — Не забудь взять что-нибудь в дорогу.

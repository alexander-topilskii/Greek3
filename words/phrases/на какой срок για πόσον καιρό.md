# База
на какой срок / как долго : για πόσον καιρό

# Формы
για - на; за
πόσον - сколько (вин.)
καιρό - время; срок
για πόσον καιρό - на какой срок; как долго

# Контекст
- **Για πόσον καιρό χρειάζεται η δουλειά;** — На какой срок нужна работа?
- **Θέλω πληροφορίες για πόσον καιρό.** — Хочу информацию, на какой срок.

# База
у вас есть аллергия? : Είστε αλλεργική σε κάτι;

# Формы
είστε - вы
αλλεργική - аллергичка
σε κάτι - на что-нибудь
Είστε αλλεργική σε κάτι; - у вас есть аллергия?

# Контекст
- **Είστε αλλεργική σε κάτι;** — У вас есть аллергия на что-нибудь?

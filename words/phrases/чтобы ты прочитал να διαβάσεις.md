# База
чтобы ты прочитал = прочитай : να διαβάσεις = διάβασε

# Формы
να διαβάσεις - чтобы ты прочитал
διάβασε - прочитай
να διαβάσεις = διάβασε - сослагательное = повелительное

# Контекст
- **Να διαβάσεις την αγγελία. = Διάβασε την αγγελία.** — Чтобы ты прочитал объявление. = Прочитай объявление.

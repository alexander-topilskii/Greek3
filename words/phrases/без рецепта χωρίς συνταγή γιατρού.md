# База
без рецепта врача : χωρίς συνταγή γιατρού

# Формы
χωρίς - без
συνταγή - рецепта
γιατρού - врача (род.)
χωρίς συνταγή γιατρού - без рецепта врача

# Контекст
- **Αυτά τα παυσίπονα είναι χωρίς συνταγή γιατρού.** — Эти обезболивающие без рецепта.

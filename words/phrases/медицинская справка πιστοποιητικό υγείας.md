# База
медицинская справка : πιστοποιητικό υγείας

# Формы
πιστοποιητικό - свидетельство; справка
υγείας - здоровья
πιστοποιητικό υγείας - медицинская справка

# Контекст
- **Χρειάζομαι πιστοποιητικό υγείας από δημόσιο νοσοκομείο.** — Нужна медицинская справка из государственной больницы.

# База
съёмные комнаты : τα ενοικιαζόμενα δωμάτια

# Формы
τα - (артикль ср. мн.)
ενοικιαζόμενα - съёмные; сдающиеся в аренду
δωμάτια - комнаты
τα ενοικιαζόμενα δωμάτια - съёмные комнаты

# Контекст
- **Στο νησί υπάρχουν φθηνά ενοικιαζόμενα δωμάτια.** — На острове есть дешёвые съёмные комнаты.

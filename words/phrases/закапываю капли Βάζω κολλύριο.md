# База
закапываю глазные капли : Βάζω κολλύριο

# Формы
Βάζω - кладу; закапываю; намазываю
κολλύριο - глазные капли
Βάζω κολλύριο - закапываю глазные капли

# Контекст
- **Βάζω κολλύριο.** — Закапываю глазные капли.
- **Βάζω κολλύριο δύο φορές την ημέρα.** — Закапываю капли два раза в день.

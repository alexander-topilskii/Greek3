# База
предлагает полупансион : προσφέρει ημιδιατροφή

# Формы
προσφέρει - он/она предлагает
ημιδιατροφή - полупансион
προσφέρει ημιδιατροφή - предлагает полупансион

# Контекст
- **Το ξενοδοχείο προσφέρει ημιδιατροφή.** — Отель предлагает полупансион.

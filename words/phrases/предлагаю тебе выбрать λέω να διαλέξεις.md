# База
я предлагаю тебе выбрать : Λέω να διαλέξεις

# Формы
λέω - я говорю; (здесь) предлагаю
να διαλέξεις - чтобы ты выбрал
Λέω να διαλέξεις - я предлагаю тебе выбрать

# Контекст
- **Λέω να διαλέξεις εσύ το ξενοδοχείο.** — Предлагаю, чтобы отель выбрал ты.
- **Λέω να πάμε νωρίς.** — Предлагаю пойти пораньше.

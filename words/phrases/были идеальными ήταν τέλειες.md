# База
были идеальными / отличными : ήταν τέλειες

# Формы
ήταν - были
τέλειες - идеальными (ж.р., мн.)
ήταν τέλειες - были идеальными (отличными)

# Контекст
- **Οι εξετάσεις ήταν τέλειες.** — Анализы были идеальными.
- **Όλες οι απαντήσεις ήταν τέλειες.** — Все ответы были отличными.

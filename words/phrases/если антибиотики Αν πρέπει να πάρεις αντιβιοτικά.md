# База
если нужно принимать антибиотики — сначала хорошо поешь : Αν πρέπει να πάρεις αντιβιοτικά, φάε καλά πριν

# Формы
αν - если
πρέπει - нужно
να πάρεις - чтобы ты принял
αντιβιοτικά - антибиотики
φάε καλά - хорошо поешь
πριν - сначала; перед этим
Αν πρέπει να πάρεις αντιβιοτικά, φάε καλά πριν - если нужно принимать антибиотики — сначала хорошо поешь

# Контекст
- **Αν πρέπει να πάρεις αντιβιοτικά, φάε καλά πριν.** — Если нужно принимать антибиотики — сначала хорошо поешь.

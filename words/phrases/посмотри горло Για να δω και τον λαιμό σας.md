# База
давайте посмотрю горло : Για να δω και τον λαιμό σας

# Формы
για να δω - чтобы я посмотрел
τον λαιμό - горло
σας - ваше
Για να δω και τον λαιμό σας - давайте посмотрю и горло

# Контекст
- **Για να δω και τον λαιμό σας. Κάντε αααα.** — Давайте посмотрю горло. Скажите «ааа».

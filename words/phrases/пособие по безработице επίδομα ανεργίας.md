# База
пособие по безработице : επίδομα ανεργίας

# Формы
επίδομα - пособие
ανεργίας - безработицы (род. п.)
επίδομα ανεργίας - пособие по безработице

# Контекст
- **Οι άνεργοι παίρνουν επίδομα ανεργίας.** — Безработные получают пособие по безработице.
- **Έκανε αίτηση για επίδομα ανεργίας.** — Он подал заявку на пособие по безработице.

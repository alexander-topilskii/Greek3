# База
пробую / пытаюсь : δοκίμασα - δοκιμάζω - θα δοκιμάσω

# Тип
Τύπος Α

# Контекст
- **Δοκιμάζω να στρίψω.** — Пробую повернуть.
- **Δοκίμασε το αυτοκίνητο.** — Попробуй машину.

# База
сержусь / сердиться : θύμωσα - θυμώνω - θα θυμώσω

# Тип
Τύπος Α

# Формы
θυμώνω - я сержусь
θυμώνεις - ты сердишься
θυμώνει - он/она сердится
θυμώνουμε - мы сердимся
θυμώνετε - вы сердитесь
θυμώνουν - они сердятся
θυμώνομαι - сердиться (страд. / разг.)

# Контекст
- **Θυμώνω όταν αργείς.** — Я сержусь, когда ты опаздываешь.
- **Μην θυμώνεις.** — Не сердись.

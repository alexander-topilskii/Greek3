# База
звоню : τηλεφώνησα - τηλεφωνώ - θα τηλεφωνήσω

# Тип
Τύπος Β1 + Β2

# Формы

τηλεφώνησα - я позвонила
τηλεφώνησες - ты позвонил

# Контекст
- **Τηλεφωνώ στη μητέρα μου κάθε μέρα.** — Я звоню маме каждый день.
- **Τηλεφώνησα στο γραφείο.** — Я позвонил в офис.

# База
иду вперёд : προχώρησα - προχωράω - θα προχωρήσω

# Тип

# Формы
προχωράω - иду вперёд
προχωράτε ευθεία - идите прямо

# Причастие

совершенное: προχωρημένος, -η, -ο

# Контекст
- **Προχωράτε ευθεία μέχρι το φανάρι.** — Идите прямо до светофора.
- **Το έργο προχωράει πολύ καλά.** — Проект продвигается очень хорошо.
- **Προχώρησα χωρίς να κοιτάξω πίσω.** — Я пошёл вперёд, не оглядываясь назад.

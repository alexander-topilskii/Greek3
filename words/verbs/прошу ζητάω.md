# База
прошу : ζήτησα - ζητάω - θα ζητήσω

# Тип
Τύπος Β1 + Β2

ζήτησαν - они попросили

ζητάω - я прошу
ζητάς - ты просишь

ζητά - оно просит

ζητάτε - вы просите
ζητάνε - они просят

θα ζητήσω - я попрошу

# Контекст
- **Ζητάω νερό, παρακαλώ.** — Прошу воды, пожалуйста.
- **Ζήτησα βοήθεια.** — Я попросил помощи.

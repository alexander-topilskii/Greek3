# База
должна / должна (деньги) : όφειλα - οφείλω - θα οφείλω

# Тип
Τύπος Β1 + Β2

# Формы
όφειλα - я должен был
όφειλα - я должна была
οφείλω - я должен
οφείλεις - ты должен
οφείλει - он должен
οφείλει - она должна
οφείλουμε - мы должны
οφείλετε - вы должны
οφείλουν - они должны

θα οφείλω - я буду должен
θα οφείλεις - ты будешь должен
θα οφείλει - он будет должен

# Контекст
- **Τι σας οφείλω;** — Сколько я вам должен?
- **Οφείλω πενήντα ευρώ.** — Я должен пятьдесят евро.

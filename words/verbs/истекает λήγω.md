# База
истекает / заканчивается : έληξα - λήγω - θα λήξω

# Тип
Τύπος Α

# Формы
έληξα - я истёк / закончился
έληξες - ты истёк
έληξε - он/она/оно истекло
λήξαμε - мы истекли
λήξατε - вы истекли
έληξαν - они истекли

λήγω - я истекаю
λήγεις - ты истекаешь
λήγει - он/она/оно истекает
λήγουμε - мы истекаем
λήγετε - вы истекаете
λήγουν - они истекают

θα λήξω - я истеку
θα λήξεις - ты истечёшь
θα λήξει - он/она/оно истечёт
θα λήξουμε - мы истечём
θα λήξετε - вы истечёте
θα λήξουν - они истекут

έληξε η σύμβασή του - закончился (истёк) его контракт

# Причастие

# Контекст
- **Έληξε η σύμβασή του τον Μάιο.** — Его контракт истёк в мае.
- **Η άδεια διαμονής λήγει σε δύο μήνες.** — Вид на жительство истекает через два месяца.

# Повелительное

# Причастие
активное: ξεναγώντας
медиопассивное: ξεναγούμενος, -η, -ο


# Контекст
- **Ο οδηγός ξεναγεί τους τουρίστες στην πόλη.** — Гид водит экскурсию для туристов по городу.
- **Μας ξενάγησε στο αρχαιολογικό μουσείο.** — Он провёл для нас экскурсию в археологическом музее.
- **Θα σε ξεναγήσω στα πιο όμορφα μέρη του νησιού.** — Я покажу тебе самые красивые места острова.

# Примеры к формам
## настоящее
### разовое
- ξεναγώ: **Ξεναγώ μια ομάδα τουριστών στην Ακρόπολη.** — Я провожу экскурсию для группы туристов по Акрополю.
- ξεναγείς: **Ξεναγείς τους φίλους σου στην παλιά πόλη;** — Ты водишь своих друзей на экскурсию по старому городу?
- ξεναγεί: **Ο επαγγελματίας ξεναγός ξεναγεί τους επισκέπτες.** — Профессиональный гид проводит экскурсию для посетителей.
- ξεναγούμε: **Ξεναγούμε τους ξένους φοιτητές στο πανεπιστήμιο.** — Мы проводим экскурсию для иностранных студентов по университету.
- ξεναγείτε: **Ξεναγείτε συχνά γκρουπ από το εξωτερικό;** — Вы часто проводите экскурсии для групп из-за рубежа?
- ξεναγούν: **Οι εθελοντές ξεναγούν το κοινό στην πινακοθήκη.** — Волонтёры проводят экскурсии для публики в картинной галерее.

### длительное
- ξεναγώ: **Ξεναγώ όλη μέρα και κουράστηκα πολύ.** — Я весь день вожу экскурсии и очень устал.
- ξεναγείς: **Ξεναγείς καθημερινά σε αυτό το μουσείο;** — Ты каждый день проводишь экскурсии в этом музее?
- ξεναγεί: **Η κοπέλα ξεναγεί με μεγάλο ενθουσιασμό.** — Девушка водит экскурсии с большим энтузиазмом.
- ξεναγούμε: **Ξεναγούμε τουρίστες όλο το καλοκαίρι.** — Мы водим экскурсии для туристов всё лето.
- ξεναγείτε: **Ξεναγείτε πάντα με τόση λεπτομέρεια;** — Вы всегда водите экскурсии так подробно?
- ξεναγούν: **Οι αρχαιολόγοι ξεναγούν συστηματικά τους μαθητές.** — Археологи систематически водят школьников на экскурсии.

### завершённое
- έχω ξεναγήσει: **Έχω ξεναγήσει εκατοντάδες ανθρώπους εδώ.** — Я провёл экскурсии для сотен людей здесь.
- έχεις ξεναγήσει: **Έχεις ξεναγήσει ποτέ VIP επισκέπτες;** — Ты когда-нибудь водил экскурсии для вип-гостей?
- έχει ξεναγήσει: **Η συνάδελφος έχει ξεναγήσει πολλές σχολικές ομάδες.** — Коллега провела экскурсии для многих школьных групп.
- έχουμε ξεναγήσει: **Έχουμε ξεναγήσει τους καλεσμένους σε όλο το κάστρο.** — Мы провели экскурсию для гостей по всему замку.
- έχετε ξεναγήσει: **Έχετε ξεναγήσει σε αυτό τον αρχαιολογικό χώρο;** — Вы проводили экскурсии на этом археологическом объекте?
- έχουν ξεναγήσει: **Οι έμπειροι ξεναγοί έχουν ξεναγήσει χιλιάδες τουρίστες.** — Опытные гиды провели экскурсии для тысяч туристов.

## прошедшее
### разовое
- ξενάγησα: **Ξενάγησα την οικογένειά μου στο κέντρο της Αθήνας.** — Я провёл экскурсию для своей семьи по центру Афин.
- ξενάγησες: **Ξενάγησες τους καλεσμένους στο ιστορικό κέντρο;** — Ты показал гостям исторический центр?
- ξενάγησε: **Ο καθηγητής ξενάγησε την τάξη στο μουσείο.** — Преподаватель провёл экскурсию для класса в музее.
- ξεναγήσαμε: **Ξεναγήσαμε τους φίλους μας στα αξιοθέατα.** — Мы провели для наших друзей экскурсию по достопримечательностям.
- ξεναγήσατε: **Ξεναγήσατε το γκρουπ στο ναό του Ποσειδώνα;** — Вы провели экскурсию для группы в храме Посейдона?
- ξενάγησαν: **Οι ειδικοί ξενάγησαν τους δημοσιογράφους στην έκθεση.** — Специалисты провели экскурсию для журналистов по выставке.

### длительное
- ξεναγούσα: **Ξεναγούσα επισκέπτες όσο δούλευα στο ίδρυμα.** — Я водил экскурсии для посетителей, пока работал в фонде.
- ξεναγούσες: **Ξεναγούσες κάθε σαββατοκύριακο στο παλάτι;** — Ты каждые выходные проводил экскурсии во дворце?
- ξεναγούσε: **Ο παππούς ξεναγούσε με καμάρι τους πάντες στο χωριό του.** — Дедушка с гордостью водил всех по своей деревне.
- ξεναγούσαμε: **Ξεναγούσαμε τουρίστες επί οκτώ ώρες την ημέρα.** — Мы водили экскурсии для туристов по восемь часов в день.
- ξεναγούσατε: **Ξεναγούσατε συχνά στα αρχαία θέατρα;** — Вы часто проводили экскурсии в древних театрах?
- ξεναγούσαν: **Οι φοιτητές ξεναγούσαν τους πρωτοετείς στις εγκαταστάσεις.** — Студенты показывали первокурсникам территорию кампуса.

### завершённое
- είχα ξεναγήσει: **Είχα ξεναγήσει το γκρουπ πριν ξεκινήσει η καταιγίδα.** — Я провёл экскурсию для группы до того, как началась буря.
- είχες ξεναγήσει: **Είχες ξεναγήσει τους επισκέπτες πριν φύγουν;** — Ты показал достопримечательности посетителям перед их отъездом?
- είχε ξεναγήσει: **Ο οδηγός είχε ξεναγήσει πολλούς τουρίστες εκείνο το πρωί.** — Гид провёл экскурсию для многих туристов тем утром.
- είχαμε ξεναγήσει: **Είχαμε ξεναγήσει όλους τους καλεσμένους πριν το μεσημέρι.** — Мы уже провели экскурсию для всех гостей до полудня.
- είχατε ξεναγήσει: **Είχατε ξεναγήσει την ομάδα πριν κλείσει το μουσείο;** — Вы провели экскурсию для группы до закрытия музея?
- είχαν ξεναγήσει: **Είχαν ξεναγήσει τους ξένους πριν από τη συνέντευξη τύπου.** — Они провели экскурсию для иностранцев до пресс-конференции.

## будущее
### разовое
- θα ξεναγήσω: **Θα ξεναγήσω τους καινούργιους συναδέλφους στο κτίριο.** — Я проведу экскурсию для новых коллег по зданию.
- θα ξεναγήσεις: **Θα ξεναγήσεις εσύ τους τουρίστες αύριο;** — Ты проведёшь экскурсию для туристов завтра?
- θα ξεναγήσει: **Η ξεναγός θα ξεναγήσει το γκρουπ στα σοκάκια του νησιού.** — Экскурсовод проведёт группу по улочкам острова.
- θα ξεναγήσουμε: **Θα ξεναγήσουμε τους καλεσμένους στον βοτανικό κήπο.** — Мы проведём экскурсию для гостей в ботаническом саду.
- θα ξεναγήσετε: **Θα ξεναγήσετε την αντιπροσωπεία στο εργοστάσιο;** — Вы покажете делегации завод?
- θα ξεναγήσουν: **Οι αρχαιολόγοι θα ξεναγήσουν το κοινό στα νέα ευρήματα.** — Археологи покажут публике новые находки.

### длительное
- θα ξεναγώ: **Θα ξεναγώ τουρίστες όλο το καλοκαίρι στα νησιά.** — Я буду водить экскурсии для туристов всё лето на островах.
- θα ξεναγείς: **Θα ξεναγείς επισκέπτες κάθε πρωί;** — Ты будешь проводить экскурсии для посетителей каждое утро?

- θα ξεναγούμε: **Θα ξεναγούμε μαθητές κάθε Παρασκευή.** — Мы будем проводить экскурсии для школьников каждую пятницу.
- θα ξεναγείτε: **Θα ξεναγείτε τακτικά σε αυτή τη γκαλερί;** — Вы будете регулярно водить экскурсии в этой галерее?
- θα ξεναγούν: **Οι ξεναγοί θα ξεναγούν ασταμάτητα στη διάρκεια της σεζόν.** — Гиды будут непрерывно водить экскурсии в течение сезона.

### завершённое
- θα έχω ξεναγήσει: **Ως το τέλος της σεζόν θα έχω ξεναγήσει χιλιάδες άτομα.** — К концу сезона я проведу экскурсии для тысяч человек.
- θα έχεις ξεναγήσει: **Θα έχεις ξεναγήσει όλους τους επισκέπτες πριν το μεσημέρι;** — Ты уже проведёшь экскурсию для всех посетителей к полудню?
- θα έχει ξεναγήσει: **Η συνάδελφος θα έχει ξεναγήσει το γκρουπ ως τις τρεις.** — Коллега уже закончит экскурсию для группы к трём часам.
- θα έχουμε ξεναγήσει: **Θα έχουμε ξεναγήσει τις ομάδες πριν κλείσει ο χώρος.** — Мы уже проведём экскурсии для групп до закрытия комплекса.
- θα έχετε ξεναγήσει: **Θα έχετε ξεναγήσει τους καλεσμένους πριν το δείπνο;** — Вы покажете гостям достопримечательности до ужина?
- θα έχουν ξεναγήσει: **Οι υπάλληλοι θα έχουν ξεναγήσει όλους τους τουρίστες ως το βράδυ.** — Сотрудники уже проведут экскурсии для всех туристов к вечеру.

## Повелительное
### разовое
- ξενάγησε: **Ξενάγησε τους φίλους σου στα ωραιότερα σημεία της πόλης!** — Проведи для своих друзей экскурсию по самым красивым местам города!
- ξεναγήστε: **Ξεναγήστε τους επισκέπτες με ευγένεια και υπομονή!** — Проведите экскурсию для посетителей с вежливостью и терпением!

### длительное
- ξενάγει: **Ξενάγει με πάθος και χαμόγελο!** — Води экскурсии со страстью и улыбкой!
- ξεναγείτε: **Ξεναγείτε πάντα με ασφάλεια και προσοχή!** — Всегда водите экскурсии безопасно и внимательно!

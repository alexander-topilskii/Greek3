# База
нужно / требуется : χρειάστηκε - χρειάζεται - θα χρειαστεί

# Тип
απρόσωπο ρήμα

# Формы
χρειάστηκε - понадобилось; потребовалось
χρειάζεται - нужно; требуется
χρειάζονται - нужны (мн.)
θα χρειαστεί - понадобится

# Контекст
- **Χρειάζεται να στείλετε το βιογραφικό σας.** — Нужно отправить ваше резюме.
- **Για πόσον καιρό χρειάζεται η δουλειά;** — На какой срок нужна работа?

# База
посещаю / слежу : παρακολουθώ

# Тип
ρήμα

# Формы
παρακολουθώ - посещаю / слежу · посетил(а) · буду посещать
παρακολούθησα - посещаю / слежу · посетил(а) · буду посещать
θα παρακολουθήσω - посещаю / слежу · посетил(а) · буду посещать

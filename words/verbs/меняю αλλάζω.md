# База
меняю / изменяю : άλλαξα - αλλάζω - θα αλλάξω

# Тип
Τύπος Α

# Формы
άλλαξα - я изменил(а)
αλλάζω - я меняю
αλλάζεις - ты меняешь
αλλάζει - он/она меняет
αλλάξει - он/она изменит (сослагат.)
θα αλλάξω - я изменю

άλλαξε - измени / поменяй (повелит., ед.)
αλλάξτε - измените (повелит., мн.)
# Контекст
- **Αν αλλάξει τίποτα, θα σου πω.** — Если что-то изменится, я тебе скажу.
- **Άλλαξε το πρόγραμμα.** — Измени расписание.

# База
договариваю / организую / улаживаю : κανόνισα - κανονίζω - θα κανονίσω

# Тип
Τύπος Α

# Формы
κανόνισα - я договорился / организовал(а)
κανονίζω - я договариваю / организую / улаживаю
κανονίζεις - ты договариваешь / организуешь
κανονίζει - он/она договаривает / организует
κανονίζουμε - мы договариваемся / организуем
κανονίζετε - вы договариваетесь / организуете
κανονίζουν - они договариваются / организуют
θα κανονίσω - я договорюсь / организую

# Контекст
- **Κανονίζω ραντεβού στο πρεσβείο.** — Я договариваюсь о встрече в посольстве.
- **Πρέπει να κανονίσω τα έγγραφα.** — Нужно уладить / оформить документы.

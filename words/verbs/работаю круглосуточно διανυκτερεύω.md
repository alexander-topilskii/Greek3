# База
работаю круглосуточно (аптека) : διανυκτέρευα - διανυκτερεύω - θα διανυκτερεύω

# Тип

# Формы
διανυκτερεύω - работаю круглосуточно
φαρμακεία που διανυκτερεύουν - круглосуточные аптеки

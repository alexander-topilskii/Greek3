# База
дежурю (о больнице) : εφημέρευα - εφημερεύω - θα εφημερεύω

# Тип
Τύπος Α

# Формы
εφημερεύω - я дежурю
εφημερεύει - дежурит (больница)
εφημερεύοντα νοσοκομεία - дежурные больницы

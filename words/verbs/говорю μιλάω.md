# База
говорю : μίλησα - μιλάω - θα μιλήσω

# Тип
Τύπος Β1 + Β2

# Формы

μίλησες - ты поговорил
μίλησε - он поговорил

μίλησε - оно поговорило
μιλήσαμε - мы поговорили
μιλήσατε - вы поговорили
μίλησαν - они поговорили

μιλάω - я говорю
μιλάς - ты говоришь
μιλά - он говорит

μιλά - оно говорит

μιλάτε - вы говорите
μιλάνε - они говорят

θα μιλήσω - я поговорю
θα μιλήσεις - ты поговоришь
θα μιλήσει - он поговорит
θα μιλήσει - она поговорит
θα μιλήσει - оно поговорит
θα μιλήσουμε - мы поговорим
θα μιλήσετε - вы поговорите
θα μιλήσουν - они поговорят
μίλησε - говори (повелит., ед.)
μιλήστε - говорите (повелит., мн.)

# Контекст
- **Μιλάω ελληνικά.** — Я говорю по-гречески.
- **Μίλησε πιο δυνατά, σε παρακαλώ.** — Говори погромче, пожалуйста.

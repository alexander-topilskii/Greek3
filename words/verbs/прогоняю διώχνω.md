# База
прогоняю : έδιωξα - διώχνω - θα διώξω

# Причастие

совершенное: διωγμένος, -η, -ο

# Контекст
- **Μην διώχνεις τον σκύλο.** — Не прогоняй собаку.
- **Ο αέρας έδιωξε τα μαύρα σύννεφα.** — Ветер прогнал чёрные тучи.
- **Έδιωξαν τους φόβους τους.** — Они прогнали свои страхи.

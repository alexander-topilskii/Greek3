# База
связываюсь : επικοινώνησα - επικοινωνώ - θα επικοινωνήσω

# Тип
Τύπος Β1

# Формы
επικοινωνώ - я связываюсь
επικοινωνήστε μαζί μου - свяжитесь со мной

# Контекст
- **Μπορείτε να επικοινωνήσετε μαζί μου με e-mail.** — Можете связаться со мной по e-mail.

# База
задыхаюсь : λαχάνιασα - λαχανιάζω - θα λαχανιάσω

# Тип
Τύπος Α

# Формы
λαχανιάζω - я задыхаюсь
λαχανιάζεις - ты задыхаешься
λαχανιάζει - он/она задыхается

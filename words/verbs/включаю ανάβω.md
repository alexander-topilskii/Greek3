# База
включаю/зажигаю : άναψα - ανάβω - θα ανάψω

# Тип
Τύπος Α

# Формы
άναψα - я включил / зажёг
άναψα - я включила / зажгла
άναψες - ты включил / зажёг
άναψε - он включил / зажёг
άναψε - она включила / зажгла
άναψε - оно включило
ανάψαμε - мы включили
ανάψατε - вы включили
άναψαν - они включили

ανάβω - я включаю / зажигаю
ανάβεις - ты включаешь / зажигаешь
ανάβει - он включает / зажигает
ανάβει - она включает / зажигает
ανάβει - оно включает
ανάβουμε - мы включаем
ανάβετε - вы включаете
ανάβουν - они включают

θα ανάψω - я включу / зажгу
θα ανάψεις - ты включишь / зажжёшь
θα ανάψει - он включит / зажжёт
θα ανάψει - она включит / зажжёт
θα ανάψει - оно включит
θα ανάψουμε - мы включим
θα ανάψετε - вы включите
θα ανάψουν - они включат

άναψε - зажги / включи (повелит., ед.)
ανάψτε - зажгите (повелит., мн.)
# Контекст
- **Ανάβω το φως.** — Я включаю свет.
- **Ανάβω την τηλεόραση.** — Я включаю телевизор.

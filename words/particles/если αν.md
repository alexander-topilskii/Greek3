# База
если : αν

# Тип
συνθήκη

# Формы
αν / εάν - если

# Контекст
- **Αν βρέξει, θα μείνουμε σπίτι.** — Если пойдёт дождь, мы останемся дома.
- **Πες μου αν χρειάζεσαι βοήθεια.** — Скажи мне, если нужна помощь.
- **Αν έχεις χρόνο, έλα.** — Если есть время, приходи.
- **Αν βρέξει, θα μείνουμε μέσα.** — Если пойдёт дождь, останемся внутри.

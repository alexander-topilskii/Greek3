# База
в течение / за : μέσα σε

# Тип
πρόθεση

# Формы
μέσα - внутри; в пределах
σε - в
μέσα σε - в течение; за (срок)

# Контекст
- **Πρέπει να κάνεις την αίτηση μέσα σε 60 ημέρες.** — Нужно подать заявление в течение 60 дней.
- **Μέσα σε δύο μήνες βρήκε δουλειά.** — За два месяца он нашёл работу.

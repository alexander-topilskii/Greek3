# База
к / по направлению к : προς

# Тип
πρόθεση

# Формы
προς - к; по направлению к; в (отношении)

# Контекст
- **Πήγε προς την εταιρεία.** — Он пошёл к компании.
- **Έχει θετική στάση προς τη δουλειά.** — У него позитивное отношение к работе.

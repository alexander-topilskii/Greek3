# База
по сравнению с / против : έναντι

# Тип
πρόθεση

# Формы
έναντι - по сравнению с; против; versus

# Контекст
- **Το ποσοστό είναι 15% έναντι 10% πέρυσι.** — Показатель составляет 15% против 10% в прошлом году.
- **Οι άνδρες είναι περισσότεροι έναντι των γυναικών.** — Мужчин больше по сравнению с женщинами.

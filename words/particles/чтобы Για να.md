# База
чтобы / для того чтобы : Για να

# Формы
για - для; чтобы
να - (связка перед глаголом)
Για να - чтобы; для того чтобы

# Контекст
- **Για να πάρω αύξηση, πρέπει να δουλέψω περισσότερο.** — Чтобы получить повышение, нужно работать больше.
- **Για να… — τι;** — Чтобы… — что?

# База
согласно / в соответствии с : σύμφωνα με

# Тип
πρόθεση

# Формы
σύμφωνα - согласно
με - с
σύμφωνα με - согласно; в соответствии с

# Контекст
- **Σύμφωνα με τη σύμβαση, ο μισθός είναι χίλια ευρώ.** — Согласно договору зарплата — тысяча евро.
- **Σύμφωνα με τον νόμο χρειάζεσαι αίτηση.** — По закону нужна заявка.

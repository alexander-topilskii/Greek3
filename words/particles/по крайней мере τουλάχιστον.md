# База
по крайней мере / как минимум : τουλάχιστον

# Тип
επίρρημα

# Формы
τουλάχιστον - по крайней мере; как минимум

# Контекст
- **Χρειάζεσαι τουλάχιστον δύο χρόνια ένσημα.** — Нужны как минимум два года страховых взносов.
- **Τουλάχιστον έξι μήνες πρέπει να είσαι άνεργος.** — Ты должен быть безработным по крайней мере шесть месяцев.

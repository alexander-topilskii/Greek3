# База
большой : μεγάλος - μεγάλη - μεγάλο

# Формы
μεγάλος - большой (м.р.)
μεγάλη - большой (ж.р.)
μεγάλο - большой (с.р.)
μεγαλύτερος - больший (м.р.)
μεγαλύτερη - большая; больше (ж.р.)
μεγαλύτερο - большее (с.р.)
είναι μεγαλύτερη - (она) больше

# Контекст
- **Μένουμε σε ένα μεγάλο σπίτι.** — Мы живём в большом доме.
- **Η Αθήνα είναι μια μεγάλη πόλη.** — Афины — большой город.
- **Η ανεργία είναι μεγαλύτερη στις γυναίκες.** — Безработица выше среди женщин.

# База
известный / знакомый : γνωστός - γνωστή - γνωστό

# Формы
γνωστός - известный; знакомый (м.р.)
γνωστή - известная; знакомая (ж.р.)
γνωστό - известное (с.р.)
γνωστοί - знакомые (мн.)
γνωστούς - знакомых / известных (вин. мн. ч., м.р.)

# Контекст
- **Ρώτησε γνωστούς για δουλειά.** — Спроси знакомых о работе.
- **Είναι γνωστός τραγουδιστής.** — Он известный певец.

# База
полезный : χρήσιμος - χρήσιμη - χρήσιμο

# Формы
χρήσιμος - полезный (м.р.)
χρήσιμη - полезная (ж.р.)
χρήσιμο - полезное (с.р.)

# Контекст
- **Αυτές οι γνώσεις είναι χρήσιμες.** — Эти знания полезны.
- **Ένα χρήσιμο δίπλωμα για τη δουλειά.** — Полезный диплом для работы.

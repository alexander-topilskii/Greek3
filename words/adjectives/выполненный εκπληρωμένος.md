# База
выполненный / исполненный : εκπληρωμένος - εκπληρωμένη - εκπληρωμένο

# Формы
εκπληρωμένος - выполненный (м.р.)
εκπληρωμένη - выполненная (ж.р.)
εκπληρωμένες στρατιωτικές υποχρεώσεις - исполненная воинская обязанность

# Контекст
- **Οι στρατιωτικές υποχρεώσεις είναι εκπληρωμένες.** — Воинская обязанность исполнена.

# База
расслабленный / непринуждённый : χαλαρός - χαλαρή - χαλαρό

# Формы
χαλαρός - расслабленный (м.р.)
χαλαρή - расслабленная (ж.р.)
χαλαρό - расслабленное (с.р.)

# Контекст
- **Δείξε χαλαρός στη συνέντευξη.** — Покажись расслабленным на собеседовании.
- **Ήταν μια χαλαρή συζήτηση.** — Это был непринуждённый разговор.

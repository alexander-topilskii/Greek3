# База
безработный : άνεργος - άνεργη

# Тип
επίθετο

# Формы
άνεργος - безработный
άνεργη - безработная
οι άνεργοι - безработные (мн. м.р.)
οι άνεργες - безработные (мн. ж.р.)

# Контекст
- **Οι άνεργοι παίρνουν επίδομα ανεργίας.** — Безработные получают пособие по безработице.
- **Είναι άνεργος τα τελευταία δύο χρόνια.** — Он безработный последние два года.

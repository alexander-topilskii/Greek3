# База
страховка / безопасность : η ασφάλεια - οι ασφάλειες

# Тип
θηλυκό

# Формы
η ασφάλεια - страховка; безопасность (ед.)
οι ασφάλειες - страховки (мн.)

# Контекст
- **Η θέση έχει ασφάλεια.** — Должность со страховкой.
- **Ρώτα για την ασφάλεια και τον μισθό.** — Спроси про страховку и зарплату.

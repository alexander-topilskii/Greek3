# База
галстук : η γραβάτα - οι γραβάτες

# Тип
θηλυκό

# Формы
η γραβάτα - галстук (ед.)
οι γραβάτες - галстуки (мн.)

# Контекст
- **Δεν θα βάλω γραβάτα.** — Я не надену галстук.
- **Φόρεσε μια μαύρη γραβάτα.** — Надень чёрный галстук.

# База
валовая зарплата (брутто) : τα μεικτά

# Тип
ουδέτερο (πληθυντικός)

# Формы
τα μεικτά - валовая зарплата; брутто (мн.)

# Контекст
- **Τα μεικτά μου είναι χίλια ευρώ.** — Моя валовая зарплата — тысяча евро.
- **Ρώτησε πόσα είναι τα μεικτά στη σύμβαση.** — Спроси, сколько брутто указано в договоре.

# База
гид / экскурсовод : ο ξεναγός - οι ξεναγοί

# Тип
αρσενικό / θηλυκό

# Формы
ο/η ξεναγός - гид (ед.)
οι ξεναγοί - гиды (мн.)

# Контекст
- **Ο ξεναγός μάς έδειξε την Ακρόπολη.** — Гид показал нам Акрополь.
- **Η ξεναγός μιλάει τρεις γλώσσες.** — Экскурсовод говорит на трёх языках.

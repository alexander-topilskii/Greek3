# База
ложка (столовая) : η κουταλιά - οι κουταλιές

# Тип
θηλυκό

# Формы
η κουταλιά - ложка (ед.)
οι κουταλιές - ложки (мн.)
μία κουταλιά - одна ложка

# Контекст
- **Μία κουταλιά της σούπας.** — Одна столовая ложка супа.
- **Δύο κουταλιές ζάχαρη.** — Две ложки сахара.

# База
удостоверение личности : η ταυτότητα - οι ταυτότητες

# Тип
θηλυκό

# Формы
η ταυτότητα - удостоверение личности; ID-карта (ед.)
οι ταυτότητες - удостоверения личности (мн.)

# Контекст
- **Για την αίτηση χρειάζεσαι ταυτότητα ή διαβατήριο.** — Для заявления нужна ID-карта или паспорт.
- **Έχεις την ταυτότητά σου μαζί σου;** — У тебя с собой удостоверение личности?

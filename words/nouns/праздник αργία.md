# База
праздник / выходной (официальный) : η αργία - οι αργίες

# Тип
θηλυκό

# Формы
η αργία - праздник; официальный выходной (ед.)
οι αργίες - праздники (мн.)

# Контекст
- **Αύριο είναι αργία και το μαγαζί θα είναι κλειστό.** — Завтра праздник, и магазин будет закрыт.
- **Τις αργίες δεν δουλεύουμε.** — В праздники мы не работаем.

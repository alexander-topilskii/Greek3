# База
мопед : το μοτοποδήλατο - τα μοτοποδήλατα

# Тип
ουδέτερο

# Формы
το μοτοποδήλατο - мопед (ед.)
τα μοτοποδήλατα - мопеды (мн.)

# Контекст
- **Απαραίτητο μοτοποδήλατο για τη θέση.** — Для должности нужен мопед.
- **Ο διανομέας έχει μοτοποδήλατο.** — У курьера есть мопед.

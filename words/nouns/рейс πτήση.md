# База
рейс / полёт : η πτήση - οι πτήσεις

# Тип
θηλυκό

# Формы
η πτήση - рейс (ед.)
οι πτήσεις - рейсы (мн.)

# Контекст
- **Η πτήση καθυστέρησε δύο ώρες.** — Рейс задержали на два часа.
- **Έκλεισα πτήση για την Αθήνα.** — Я забронировал рейс в Афины.

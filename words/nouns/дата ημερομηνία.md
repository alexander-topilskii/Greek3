# База
дата : η ημερομηνία - οι ημερομηνίες

# Тип
θηλυκό

# Формы
η ημερομηνία - дата (ед.)
οι ημερομηνίες - даты (мн.)
ημερομηνία λήξης - дата истечения

# Контекст
- **Γράψε την ημερομηνία στην αίτηση.** — Напиши дату в заявлении.
- **Ποια είναι η ημερομηνία λήξης της σύμβασης;** — Какая дата окончания контракта?

# База
работодатель / начальник : ο εργοδότης - οι εργοδότες / η εργοδότρια - οι εργοδότριες / το αφεντικό - τα αφεντικά

# Тип
αρσενικό / θηλυκό / ουδέτερο

# Формы
ο εργοδότης - работодатель (м.р.)
η εργοδότρια - работодательница (ж.р.)
οι εργοδότες - работодатели (мн.)
οι εργοδότριες - работодательницы (мн.)
το αφεντικό - начальник; хозяин (разг., с.р.)
τα αφεντικά - начальники (разг., мн.)

# Контекст
- **Ο εργοδότης μου είναι δίκαιος.** — Мой работодатель справедливый.
- **Το αφεντικό θέλει να μιλήσουμε αύριο.** — Начальник хочет поговорить с нами завтра.

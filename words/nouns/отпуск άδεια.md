# База
отпуск / разрешение : η άδεια - οι άδειες

# Тип
θηλυκό

# Формы
η άδεια - отпуск; разрешение (ед.)
οι άδειες - отпуска; разрешения (мн.)
Θα πάρει άδεια - он/она возьмёт отпуск
άδεια διαμονής - вид на жительство (ВНЖ)

# Контекст
- **Θα πάρει άδεια τον Αύγουστο.** — Он возьмёт отпуск в августе.
- **Η συνάδελφός μου θα πάρει άδεια δύο εβδομάδες.** — Моя коллега возьмёт отпуск на две недели.
- **Έχω άδεια διαμονής στην Ελλάδα.** — У меня вид на жительство в Греции.

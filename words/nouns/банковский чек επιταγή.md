# База
чек (банковский / почтовый) : η επιταγή - οι επιταγές

# Тип
θηλυκό

# Формы
η επιταγή - чек
ταχυδρομική επιταγή - почтовый перевод

# Контекст
- **Με πληρώνουν με επιταγή.** — Мне платят чеком.
- **Εξαργυρώνω την επιταγή.** — Обналичиваю чек.

# База
отправление / вылет : η αναχώρηση - οι αναχωρήσεις

# Тип
θηλυκό

# Формы
η αναχώρηση - отправление (ед.)
οι αναχωρήσεις - отправления (мн.)

# Контекст
- **Η αναχώρηση είναι στις οκτώ το πρωί.** — Вылет в восемь утра.
- **Ποια ώρα είναι η αναχώρηση του τρένου;** — Во сколько отправление поезда?

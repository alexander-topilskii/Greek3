# База
маршрут / расписание : το δρομολόγιο - τα δρομολόγια

# Тип
ουδέτερο

# Формы
το δρομολόγιο - маршрут (ед.)
τα δρομολόγια - маршруты; расписание (мн.)

# Контекст
- **Ποιο είναι το δρομολόγιο του πλοίου;** — Какое расписание у парома?
- **Άλλαξαν το δρομολόγιο του λεωφορείου.** — Изменили маршрут автобуса.

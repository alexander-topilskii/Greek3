# База
ксерокопия : η φωτοτυπία / το φωτοαντίγραφο

# Тип
θηλυκό

# Формы
η φωτοτυπία - ксерокопия
το φωτοαντίγραφο - фотокопия
επικυρωμένη φωτοτυπία - заверенная копия

# Контекст
- **Χρειάζομαι επικυρωμένη φωτοτυπία.** — Мне нужна заверенная копия.

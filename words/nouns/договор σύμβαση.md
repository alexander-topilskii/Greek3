# База
договор / контракт : η σύμβαση - οι συμβάσεις

# Тип
θηλυκό

# Формы
η σύμβαση - договор; контракт (ед.)
οι συμβάσεις - договоры (мн.)

# Контекст
- **Τι σύμβαση θα υπογράψεις;** — Какой договор ты подпишешь?
- **Διάβασε τη σύμβαση προσεκτικά.** — Внимательно прочитай договор.

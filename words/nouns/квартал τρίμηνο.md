# База
квартал : το τρίμηνο - τα τρίμηνα

# Тип
ουδέτερο

# Формы
το τρίμηνο - квартал (ед.)
τα τρίμηνα - кварталы (мн.)
το δεύτερο τρίμηνο - второй квартал

# Контекст
- **Το δεύτερο τρίμηνο η ανεργία έπεσε.** — Во втором квартале безработица снизилась.
- **Κάθε τρίμηνο βγαίνουν νέα στοιχεία.** — Каждый квартал выходят новые данные.

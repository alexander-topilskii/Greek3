# База
паспорт : το διαβατήριο - τα διαβατήρια

# Тип
ουδέτερο

# Формы
το διαβατήριο - паспорт (ед.)
τα διαβατήρια - паспорта (мн.)

# Контекст
- **Το διαβατήριο είναι στο συρτάρι.** — Паспорт в ящике стола.
- **Χωρίς διαβατήριο δεν μπορείς να ταξιδέψεις στο εξωτερικό.** — Без паспорта нельзя поехать за границу.

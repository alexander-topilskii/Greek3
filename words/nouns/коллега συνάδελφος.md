# База
коллега : ο συνάδελφος - οι συνάδελφοι / η συνάδελφος - οι συνάδελφοι

# Тип
κοινό

# Формы
ο συνάδελφος - коллега (м.р.)
η συνάδελφος - коллега (ж.р.)
οι συνάδελφοι - коллеги (мн.)

# Контекст
- **Η συνάδελφός μου δουλεύει μερικής απασχόλησης.** — Моя коллега работает на частичной занятости.
- **Μιλάω με τους συναδέλφους μου κάθε μέρα.** — Я разговариваю с коллегами каждый день.

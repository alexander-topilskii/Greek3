# База
данные / статистика : το στοιχείο - τα στοιχεία

# Тип
ουδέτερο

# Формы
το στοιχείο - элемент; пункт (ед.)
τα στοιχεία - данные; статистика (мн.)
στατιστικά στοιχεία - статистические данные

# Контекст
- **Τα στοιχεία δείχνουν αύξηση της ανεργίας.** — Данные показывают рост безработицы.
- **Σύμφωνα με τα στοιχεία, οι άνεργοι είναι περισσότεροι.** — Согласно данным, безработных больше.

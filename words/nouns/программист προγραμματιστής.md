# База
программист : ο προγραμματιστής - οι προγραμματιστές

# Тип
αρσενικό

# Формы
ο προγραμματιστής - программист (ед.)
οι προγραμματιστές - программисты (мн.)

# Контекст
- **Δουλεύει ως προγραμματιστής.** — Он работает программистом.
- **Ζητείται προγραμματιστής με εμπειρία.** — Требуется программист с опытом.

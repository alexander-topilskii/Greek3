# База
страхование : η ασφάλιση - οι ασφαλίσεις

# Тип
θηλυκό

# Формы
η ασφάλιση - страхование (ед.)
οι ασφαλίσεις - виды страхования (мн.)

# Контекст
- **Ρώτησε για την ασφάλιση.** — Спроси про страхование.
- **Η ασφάλιση καλύπτει και τα φάρμακα.** — Страховка покрывает и лекарства.

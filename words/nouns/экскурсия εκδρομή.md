# База
экскурсия / поездка : η εκδρομή - οι εκδρομές

# Тип
θηλυκό

# Формы
η εκδρομή - экскурсия (ед.)
οι εκδρομές - экскурсии (мн.)

# Контекст
- **Πήγαμε εκδρομή στα νησιά.** — Мы поехали на экскурсию на острова.
- **Η εκδρομή διαρκεί μία μέρα.** — Экскурсия длится один день.

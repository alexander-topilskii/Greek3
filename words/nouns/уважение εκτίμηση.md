# База
уважение : η εκτίμηση

# Тип
θηλυκό

# Формы
η εκτίμηση - уважение; оценка
Με εκτίμηση - с уважением

# Контекст
- **Με εκτίμηση, Νίκος Παπαδόπουλος.** — С уважением, Никос Пападопулос.
- **Έχει εκτίμηση στους συναδέλφους.** — Он уважает коллег.

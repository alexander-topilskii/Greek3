# База
опыт : η εμπειρία - οι εμπειρίες

# Тип
θηλυκό

# Формы
η εμπειρία - опыт (ед.)
οι εμπειρίες - опыты (мн.)
σχετική εμπειρία - соответствующий / релевантный опыт

# Контекст
- **Έχετε σχετική εμπειρία;** — У вас есть соответствующий опыт?
- **Έχετε εμπειρία σε αυτό το επάγγελμα;** — У вас есть опыт в этой профессии?

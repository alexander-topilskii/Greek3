# База
зной / сильная жара : ο καύσωνας - οι καύσωνες

# Тип
αρσενικό

# Формы
ο καύσωνας - зной; сильная жара (ед.)
οι καύσωνες - периоды зноя (мн.)

# Контекст
- **Έχει καύσωνα, άναψε το κλιματιστικό.** — Зной — включи кондиционер.
- **Στον καύσωνα μείνε μέσα.** — В сильную жару оставайся дома.

# База
должность / место : η θέση - οι θέσεις

# Тип
θηλυκό

# Формы
η θέση - должность; место (ед.)
οι θέσεις - должности; места (мн.)
τη θέση - должность; место (вин.)
δεύτερη θέση - второе место

# Контекст
- **Ενδιαφέρομαι για τη θέση υπαλλήλου ρεσεψιόν.** — Меня интересует вакансия сотрудника на ресепшене.
- **Είναι μια υπεύθυνη θέση.** — Это ответственная должность.
- **Η χώρα είναι στη δεύτερη θέση.** — Страна на втором месте.

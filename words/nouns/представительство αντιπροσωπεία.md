# База
представительство : η αντιπροσωπεία - οι αντιπροσωπείες

# Тип
θηλυκό

# Формы
η αντιπροσωπεία - представительство (ед.)
οι αντιπροσωπείες - представительства (мн.)

# Контекст
- **Δουλεύει σε αντιπροσωπεία αυτοκινήτων.** — Он работает в автопредставительстве.
- **Η αντιπροσωπεία ζητάει οδηγό.** — Представительство ищет водителя.

# База
техник : ο τεχνικός - οι τεχνικοί

# Тип
αρσενικό

# Формы
ο τεχνικός - техник (ед.)
οι τεχνικοί - техники (мн.)

# Контекст
- **Ζητείται τεχνικός υπολογιστών.** — Требуется компьютерный техник.
- **Ο τεχνικός ήρθε αμέσως.** — Техник пришёл сразу.

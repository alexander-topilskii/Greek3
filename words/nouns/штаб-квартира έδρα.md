# База
штаб-квартира / место регистрации : η έδρα - οι έδρες

# Тип
θηλυκό

# Формы
η έδρα - штаб-квартира; юридический адрес (ед.)
οι έδρες - штаб-квартиры (мн.)

# Контекст
- **Η έδρα της εταιρείας είναι στην Αθήνα.** — Штаб-квартира компании в Афинах.
- **Γράψε την έδρα στην αίτηση.** — Укажи юридический адрес в заявлении.

# База
талия / поясница : η μέση - οι μέσες

# Тип
θηλυκό

# Формы
η μέση - талия; поясница; середина (ед.)
οι μέσες - талии (мн.)

# Контекст
- **Με πονάει η μέση.** — У меня болит поясница.
- **Φοράει ζώνη στη μέση.** — Он носит ремень на талии.

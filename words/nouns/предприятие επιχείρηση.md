# База
предприятие / фирма : η επιχείρηση - οι επιχειρήσεις

# Тип
θηλυκό

# Формы
η επιχείρηση - предприятие; фирма (ед.)
οι επιχειρήσεις - предприятия (мн.)

# Контекст
- **Δουλεύει σε μια μικρή επιχείρηση.** — Он работает на небольшом предприятии.
- **Η επιχείρηση ζητάει υπάλληλο.** — Фирма ищет сотрудника.

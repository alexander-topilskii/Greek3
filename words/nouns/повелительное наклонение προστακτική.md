# База
повелительное наклонение : η προστακτική

# Тип
θηλυκό

# Формы
η προστακτική - повелительное наклонение
αρνητική προστακτική - отрицательное повелительное

# Контекст
- **Η προστακτική λέει «κάνε» και «κάντε».** — Повелительное говорит «сделай» и «сделайте».
- **Η αρνητική προστακτική είναι «μη διαβάσεις».** — Отрицательное повелительное — «не читай».

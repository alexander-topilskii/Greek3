# База
обезболивающее : το παυσίπονο - τα παυσίπονα

# Тип
ουδέτερο

# Формы
το παυσίπονο - обезболивающее (ед.)
τα παυσίπονα - обезболивающие (мн.)

# Контекст
- **Πάρε ένα παυσίπονο για τον πονοκέφαλο.** — Прими обезболивающее от головной боли.

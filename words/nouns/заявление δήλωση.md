# База
заявление / декларация : η δήλωση - οι δηλώσεις

# Тип
θηλυκό

# Формы
η δήλωση - заявление; декларация (ед.)
οι δηλώσεις - заявления (мн.)
υπεύθυνη δήλωση - официальное заявление под личную ответственность
δήλωση στην εφορία - декларация в налоговую

# Контекст
- **Έκανε δήλωση στην εφορία.** — Он подал декларацию в налоговую.
- **Χρειάζονται υπεύθυνη δήλωση.** — Нужно официальное заявление под личную ответственность.

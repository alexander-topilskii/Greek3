# База
занятость : η απασχόληση

# Тип
θηλυκό

# Формы
η απασχόληση - занятость
μερική απασχόληση - частичная занятость
μόνιμη απασχόληση - постоянная занятость

# Контекст
- **Ψάχνω μερική απασχόληση.** — Ищу частичную занятость.
- **Η αγγελία είναι για μόνιμη απασχόληση.** — Объявление о постоянной занятости.

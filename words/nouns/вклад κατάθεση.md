# База
вклад / внесение денег : η κατάθεση - οι καταθέσεις

# Тип
θηλυκό

# Формы
η κατάθεση - вклад; внесение денег; подача документов
κάνω μια κατάθεση - делаю вклад / вношу деньги

# Контекст
- **Θέλω να κάνω μια κατάθεση.** — Хочу внести деньги.
- **Καταθέτω τον φάκελο στο ΚΕΠ.** — Подаю пакет документов в КЕП.

# База
сверхурочная работа : η υπερωρία - οι υπερωρίες

# Тип
θηλυκό

# Формы
η υπερωρία - сверхурочная работа (ед.)
οι υπερωρίες - сверхурочные (мн.)

# Контекст
- **Δουλεύω υπερωρία κάθε Παρασκευή.** — Я работаю сверхурочно каждую пятницу.
- **Πληρώνουν την υπερωρία καλύτερα.** — За сверхурочные платят лучше.

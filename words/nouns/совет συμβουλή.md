# База
совет : η συμβουλή - οι συμβουλές

# Тип
θηλυκό

# Формы
η συμβουλή - совет (ед.)
οι συμβουλές - советы (мн.)

# Контекст
- **Μου έδωσε μια καλή συμβουλή.** — Он дал мне хороший совет.
- **Άκου τις συμβουλές του διευθυντή.** — Слушай советы директора.

# База
образец / шаблон : το πρότυπο - τα πρότυπα

# Тип
ουδέτερο

# Формы
το πρότυπο - образец; шаблон (ед.)
τα πρότυπα - образцы (мн.)

# Контекст
- **Γράψε την επιστολή με αυτό το πρότυπο.** — Напиши письмо по этому образцу.
- **Το πρότυπο είναι στο βιβλίο.** — Образец в учебнике.

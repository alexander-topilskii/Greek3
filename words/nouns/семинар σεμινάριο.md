# База
семинар : το σεμινάριο - τα σεμινάρια

# Тип
ουδέτερο

# Формы
το σεμινάριο - семинар (ед.)
τα σεμινάρια - семинары (мн.)

# Контекст
- **Έκανα ένα σεμινάριο για υπολογιστές.** — Я прошёл семинар по компьютерам.
- **Τα σεμινάρια μπαίνουν στο βιογραφικό.** — Семинары указывают в резюме.

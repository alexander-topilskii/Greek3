# База
резюме / CV : το βιογραφικό - τα βιογραφικά

# Тип
ουδέτερο

# Формы
το βιογραφικό - резюме (ед.)
τα βιογραφικά - резюме (мн.)
το βιογραφικό σας - ваше резюме

# Контекст
- **Στείλτε το βιογραφικό σας στη διεύθυνση.** — Отправьте ваше резюме по адресу.
- **Έβαλα το βιογραφικό μου στον φάκελο.** — Я положил(а) своё резюме в папку.

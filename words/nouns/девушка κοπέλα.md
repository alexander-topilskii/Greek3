# База
девушка / официантка (разг.) : η κοπέλα - οι κοπέλες

# Тип
θηλυκό

# Формы
η κοπέλα - девушка; официантка (разг.) (ед.)
οι κοπέλες - девушки; официантки (разг.) (мн.)

# Контекст
- **Κοπέλες, τον λογαριασμό, παρακαλώ!** — Девочки, счёт, пожалуйста!
- **Οι κοπέλες στο εστιατόριο είναι πολύ ευγενικές.** — Девушки в ресторане очень вежливые.

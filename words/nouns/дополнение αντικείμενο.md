# База
дополнение (грам.) : το αντικείμενο - τα αντικείμενα

# Тип
ουδέτερο

# Формы
το αντικείμενο - дополнение; объект (ед.)
τα αντικείμενα - дополнения (мн.)

# Контекст
- **Η αντωνυμία είναι αντικείμενο: «Κοίταξέ με».** — Местоимение — дополнение: «Посмотри на меня».

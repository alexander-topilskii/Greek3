# База
забастовка : η απεργία - οι απεργίες

# Тип
θηλυκό

# Формы
η απεργία - забастовка (ед.)
οι απεργίες - забастовки (мн.)

# Контекст
- **Αύριο έχουμε απεργία.** — Завтра у нас забастовка.
- **Οι εργαζόμενοι κάνουν απεργία για καλύτερο μισθό.** — Работники бастуют за лучшую зарплату.

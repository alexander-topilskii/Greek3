# База
операция : η εγχείριση - οι εγχειρίσεις

# Тип
θηλυκό

# Формы
η εγχείριση - операция (ед.)
οι εγχειρίσεις - операции (мн.)

# Контекст
- **Χρειάζεται εγχείριση.** — Нужна операция.
- **Η εγχείριση πήγε καλά.** — Операция прошла хорошо.

# База
проживание / пребывание : η διαμονή

# Тип
θηλυκό

# Формы
η διαμονή - проживание; пребывание
άδεια διαμονής - вид на жительство (ВНЖ)

# Контекст
- **Έχω άδεια διαμονής στην Ελλάδα.** — У меня вид на жительство в Греции.
- **Η διαμονή στο ξενοδοχείο είναι για μία εβδομάδα.** — Проживание в отеле — на одну неделю.

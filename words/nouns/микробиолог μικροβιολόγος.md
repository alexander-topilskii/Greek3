# База
лаборант / микробиолог : ο/η μικροβιολόγος - οι μικροβιολόγοι

# Тип
αρσενικό / θηλυκό

# Формы
ο/η μικροβιολόγος - микробиолог; лаборатория анализов

# Контекст
- **Κάνω εξετάσεις αίματος στον μικροβιολόγο.** — Сдаю анализы крови в лаборатории.

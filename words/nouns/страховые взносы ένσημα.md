# База
страховые взносы / «марки» : τα ένσημα

# Тип
ουδέτερο (πληθυντικός)

# Формы
τα ένσημα - страховые взносы; «марки» (мн.)

# Контекст
- **Ο εργοδότης πληρώνει τα ένσημα.** — Работодатель платит страховые взносы.
- **Χωρίς ένσημα δεν έχεις ασφάλιση.** — Без взносов у тебя нет страховки.

# База
пособие : το επίδομα - τα επιδόματα

# Тип
ουδέτερο

# Формы
το επίδομα - пособие (ед.)
τα επιδόματα - пособия (мн.)
επίδομα ανεργίας - пособие по безработице

# Контекст
- **Παίρνει επίδομα ανεργίας.** — Он получает пособие по безработице.
- **Το επίδομα έρχεται κάθε μήνα.** — Пособие приходит каждый месяц.

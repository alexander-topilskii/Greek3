# База
сотрудник : ο υπάλληλος - οι υπάλληλοι

# Тип
αρσενικό

# Формы
ο υπάλληλος - сотрудник (ед.)
οι υπάλληλοι - сотрудники (мн.)
υπαλλήλου - сотрудника (род.)

# Контекст
- **Η θέση υπαλλήλου ρεσεψιόν είναι ανοιχτή.** — Вакансия сотрудника на ресепшене открыта.
- **Οι υπάλληλοι της εταιρείας είναι ευγενικοί.** — Сотрудники компании вежливы.

# База
медицинская книжка / полис : το βιβλιάριο υγείας - τα βιβλιάρια υγείας

# Тип
ουδέτερο

# Формы
το βιβλιάριο - книжка; полис (ед.)
το βιβλιάριο υγείας - медицинская книжка / полис

# Контекст
- **Πάρε μαζί το βιβλιάριο υγείας.** — Возьми с собой медицинскую книжку.
- **Για το επίδομα χρειάζεσαι βιβλιάριο υγείας.** — Для пособия нужна медицинская книжка.

# База
приказ : η εντολή - οι εντολές

# Тип
θηλυκό

# Формы
η εντολή - приказ; распоряжение (ед.)
οι εντολές - приказы (мн.)

# Контекст
- **Αυτή είναι εντολή, όχι συμβουλή.** — Это приказ, а не совет.
- **Άκουσε τις εντολές και φύγε.** — Выслушай приказы и уходи.

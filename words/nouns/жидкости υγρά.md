# База
жидкости : τα υγρά

# Тип
ουδέτερο (συνήθως στο πληθυντικό)

# Формы
τα υγρά - жидкости; питьё

# Контекст
- **Πιείτε πολλά υγρά.** — Пейте много жидкости.
- **Όταν είσαι άρρωστος, χρειάζεσαι υγρά.** — Когда болеешь, нужно пить больше жидкости.

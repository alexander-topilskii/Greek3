# База
трансфер / передвижение : η μετακίνηση - οι μετακινήσεις

# Тип
θηλυκό

# Формы
η μετακίνηση - трансфер (ед.)
οι μετακινήσεις - трансферы (мн.)

# Контекст
- **Οι μετακινήσεις περιλαμβάνονται στην τιμή.** — Трансферы включены в цену.
- **Η μετακίνηση από το αεροδρόμιο είναι δωρεάν.** — Трансфер из аэропорта бесплатный.

# База
профессия : το επάγγελμα - τα επαγγέλματα

# Тип
ουδέτερο

# Формы
το επάγγελμα - профессия (ед.)
τα επαγγέλματα - профессии (мн.)
αυτό το επάγγελμα - эта профессия

# Контекст
- **Έχετε προϋπηρεσία σε αυτό το επάγγελμα;** — У вас есть стаж в этой профессии?
- **Τι επάγγελμα κάνεις;** — Кем ты работаешь?

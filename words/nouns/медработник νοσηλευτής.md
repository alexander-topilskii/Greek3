# База
медработник : ο νοσηλευτής - οι νοσηλευτές / η νοσηλεύτρια

# Тип
αρσενικό / θηλυκό

# Формы
ο νοσηλευτής - медбрат
η νοσηλεύτρια - медсестра

# Контекст
- **Δουλεύει νοσηλευτής στο νοσοκομείο.** — Он работает медбратом в больнице.

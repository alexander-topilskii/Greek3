# База
начисление зарплаты / ведомость : η μισθοδοσία

# Тип
θηλυκό

# Формы
η μισθοδοσία - начисление зарплаты; зарплатная ведомость

# Контекст
- **Κάνει μισθοδοσία στο λογιστήριο.** — Она ведёт зарплату в бухгалтерии.
- **Ο χειρισμός μισθοδοσίας είναι απαραίτητος.** — Владение зарплатной программой обязательно.

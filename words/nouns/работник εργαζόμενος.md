# База
работник / сотрудник : ο εργαζόμενος - οι εργαζόμενοι / η εργαζόμενη - οι εργαζόμενες

# Тип
αρσενικό / θηλυκό

# Формы
ο εργαζόμενος - работник; сотрудник (м.р.)
η εργαζόμενη - работница; сотрудница (ж.р.)
οι εργαζόμενοι - работники (мн.)
οι εργαζόμενες - работницы (мн.)

# Контекст
- **Οι εργαζόμενοι έχουν δικαίωμα σε άδεια.** — Работники имеют право на отпуск.
- **Η εργαζόμενη στο εστιατόριο ζήτησε αύξηση.** — Сотрудница ресторана попросила повышение.

# База
салат : η σαλάτα - οι σαλάτες

# Тип
θηλυκό

# Формы
η σαλάτα - салат (ед.)
οι σαλάτες - салаты (мн.)

# Контекст
- **Φτιάξε μια σαλάτα για το πάρτι.** — Сделай салат к вечеринке.
- **Πάρε ντομάτες για σαλάτα.** — Возьми помидоры на салат.

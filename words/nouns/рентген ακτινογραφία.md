# База
рентген : η ακτινογραφία - οι ακτινογραφίες

# Тип
θηλυκό

# Формы
η ακτινογραφία - рентген (ед.)
οι ακτινογραφίες - рентгены (мн.)

# Контекст
- **Θέλω να κάνω μία ακτινογραφία.** — Хочу сделать рентген.
- **Η ακτινογραφία είναι καθαρή.** — На рентгене всё чисто.

# База
заявка / заявление : η αίτηση - οι αιτήσεις

# Тип
θηλυκό

# Формы
η αίτηση - заявка; заявление (ед.)
οι αιτήσεις - заявки (мн.)
την αίτηση - заявку (вин.)
κάνω αίτηση - подаю заявку

# Контекст
- **Έκανα αίτηση για επίδομα ανεργίας.** — Я подал заявку на пособие по безработице.
- **Πρέπει να κάνεις την αίτηση μέσα σε 60 ημέρες.** — Нужно подать заявление в течение 60 дней.

# База
карьера : η καριέρα / η σταδιοδρομία

# Тип
θηλυκό

# Формы
η καριέρα - карьера
η σταδιοδρομία - карьера; профессиональный путь
Καλή σταδιοδρομία! - успешной карьеры!

# Контекст
- **Θέλει καριέρα στον τουρισμό.** — Он хочет карьеру в туризме.
- **Καλή σταδιοδρομία!** — Успешной карьеры!

# База
субфебрильная температура : τα δέκατα

# Тип
ουδέτερο (πληθυντικό)

# Формы
τα δέκατα - субфебрильная температура; «десятые»
δέκατα - субфебрильная температура

# Контекст
- **Έχω δέκατα.** — У меня небольшая температура.
- **Δεν έχει πυρετό, μόνο δέκατα.** — Жара нет, только небольшая температура.

# База
служба / услуга : η υπηρεσία - οι υπηρεσίες

# Тип
θηλυκό

# Формы
η υπηρεσία - служба; услуга
οι υπηρεσίες - службы; услуги
δημόσιες υπηρεσίες - государственные службы
διάφορες υπηρεσίες - различные службы

# Контекст
- **Το ΚΕΠ συνεργάζεται με διάφορες υπηρεσίες.** — КЕП сотрудничает с различными службами.
- **Ποιες υπηρεσίες προσφέρουν τα ΚΕΠ;** — Какие услуги предоставляют КЕП?

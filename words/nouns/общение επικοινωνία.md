# База
связь / общение : η επικοινωνία - οι επικοινωνίες

# Тип
θηλυκό

# Формы
η επικοινωνία - связь; общение (ед.)
οι επικοινωνίες - коммуникации (мн.)

# Контекст
- **Για επικοινωνία καλέστε το τηλέφωνο.** — Для связи звоните по телефону.
- **Η επικοινωνία με την εταιρεία είναι εύκολη.** — Связаться с компанией легко.

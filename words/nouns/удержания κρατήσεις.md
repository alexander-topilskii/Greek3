# База
удержания (из зарплаты) : οι κρατήσεις

# Тип
θηλυκό (πληθυντικός)

# Фορмы
οι κρατήσεις - удержания; вычеты (мн.)

# Контекст
- **Οι κρατήσεις από τον μισθό είναι πολλές.** — Удержания из зарплаты большие.
- **Μετά τις κρατήσεις μένουν τα καθαρά.** — После удержаний остаётся нетто.

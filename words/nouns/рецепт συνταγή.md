# База
рецепт : η συνταγή - οι συνταγές

# Тип
θηλυκό

# Формы
η συνταγή - рецепт (ед.)
οι συνταγές - рецепты (мн.)

# Контекст
- **Χρειάζομαι συνταγή για τα φάρμακα.** — Мне нужен рецепт на лекарства.
- **Ο γιατρός μου έδωσε μια συνταγή.** — Врач выписал мне рецепт.

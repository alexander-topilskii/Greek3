# База
рецепт (медицинский) : η συνταγή - οι συνταγές

# Тип
θηλυκό

# Формы
η συνταγή - рецепт (ед.)
οι συνταγές - рецепты (мн.)

# Контекст
- **Ο γιατρός έδωσε συνταγή.** — Врач выписал рецепт.
- **Χρειάζομαι συνταγή για τα χάπια.** — Мне нужен рецепт на таблетки.

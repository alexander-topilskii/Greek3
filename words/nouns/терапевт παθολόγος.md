# База
терапевт : ο/η παθολόγος - οι παθολόγοι

# Тип
αρσενικό / θηλυκό

# Формы
ο/η παθολόγος - терапевт (ед.)
οι παθολόγοι - терапевты (мн.)
τον/την παθολόγο - терапевта (вин.)

# Контекст
- **Πήγα στον παθολόγο.** — Я сходил к терапевту.
- **Η παθολόγος μού έγραψε εξετάσεις.** — Терапевт выписала мне анализы.

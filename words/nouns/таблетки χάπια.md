# База
таблетки : τα χάπια

# Тип
ουδέτερο (συνήθως στο πληθυντικό)

# Формы
το χάπι - таблетка (ед.)
τα χάπια - таблетки (мн.)

# Контекст
- **Πάρε ένα χάπι κάθε 8 ώρες.** — Принимай по таблетке каждые 8 часов.
- **Τα χάπια είναι στο φαρμακείο.** — Таблетки в аптеке.

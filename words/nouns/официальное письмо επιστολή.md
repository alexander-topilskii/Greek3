# База
официальное письмо : η επιστολή - οι επιστολές

# Тип
θηλυκό

# Формы
η επιστολή - официальное письмо (ед.)
οι επιστολές - письма (мн.)

# Контекст
- **Έγραψε μια επιστολή στον εργοδότη.** — Он написал письмо работодателю.
- **Η επιστολή αρχίζει με «Αξιότιμε κύριε».** — Письмо начинается с «Уважаемый господин».

# База
склад : η αποθήκη - οι αποθήκες

# Тип
θηλυκό

# Формы
η αποθήκη - склад (ед.)
οι αποθήκες - склады (мн.)

# Контекст
- **Δουλεύει στην αποθήκη ενός βιβλιοπωλείου.** — Он работает на складе книжного магазина.
- **Τα βιβλία είναι στην αποθήκη.** — Книги на складе.

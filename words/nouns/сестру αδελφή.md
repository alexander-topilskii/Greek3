# База
сестра (вин. п.) : την αδελφή

# Тип
πτώση · αιτιατική

# Формы
την αδελφή - сестру (ед., ж.р., винительный)
αδελφή - сестра / сестру (форма на −η)

# Контекст
- **Αγαπώ την αδελφή μου.** — Я люблю мою сестру.
- **Βλέπω την αδελφή του κάθε μέρα.** — Я вижу его сестру каждый день.

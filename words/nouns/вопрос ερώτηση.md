# База
вопрос : η ερώτηση - οι ερωτήσεις

# Тип
θηλυκό

# Формы
η ερώτηση - вопрос (ед.)
οι ερωτήσεις - вопросы (мн.)

# Контекст
- **Απάντησε στις ερωτήσεις χωρίς άγχος.** — Отвечай на вопросы без тревоги.
- **Έκανα μια ερώτηση για το ωράριο.** — Я задал вопрос про график работы.

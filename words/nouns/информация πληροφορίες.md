# База
информация : η πληροφορία - οι πληροφορίες

# Тип
θηλυκό

# Формы
η πληροφορία - информация (ед.)
οι πληροφορίες - информация (мн.)
πληροφορίες - сведения; информация

# Контекст
- **Χρειάζομαι πληροφορίες για τη θέση.** — Мне нужна информация о вакансии.
- **Δώστε μου πληροφορίες για πόσον καιρό.** — Дайте мне информацию, на какой срок.

# База
пенсия : η σύνταξη - οι συντάξεις

# Тип
θηλυκό

# Формы
η σύνταξη - пенсия (ед.)
οι συντάξεις - пенсии (мн.)

# Контекст
- **Ο πατέρας μου πήρε σύνταξη φέτος.** — Мой отец в этом году вышел на пенсию.
- **Η σύνταξη δεν είναι αρκετή.** — Пенсии недостаточно.

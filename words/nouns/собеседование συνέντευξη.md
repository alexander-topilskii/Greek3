# База
собеседование : η συνέντευξη - οι συνεντεύξεις

# Тип
θηλυκό

# Формы
η συνέντευξη - собеседование (ед.)
οι συνεντεύξεις - собеседования (мн.)

# Контекст
- **Έχω συνέντευξη αύριο.** — У меня завтра собеседование.
- **Πήγα στη συνέντευξη με κοστούμι.** — Я пошёл на собеседование в костюме.
